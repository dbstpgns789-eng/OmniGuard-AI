# 01. 발·바닥 평면(BEV) 기반 위험구역 감시 (Aside, 2026-10-19)

결론: 1주일·CPU·사전학습 모델로 가능한 조합은 사용자가 찍은 4점 호모그래피 + 사람 키로 만든 원근 맵 + 발이 가려졌을 때의 대체 규칙 + ISO 공식으로 정한 구역 크기 + 이동 방향 게이트. 깊이 모델과 3D 포즈는 빼는 편이 낫다. 일부 원문은 403으로 막혀 초록만 확인.

## A. "닿을 수 있는 거리" 규칙 (표준)
1. **ISO 13855 (Keyence 해설)** https://www.keyence.com/ss/products/safetyknowledge/caution — S = K×T + C. 몸 전체 K=1600mm/s, C=850mm. 손 K=2000mm/s(S≥500mm면 1600으로 재계산). 예: T=0.1069s → S=1021mm. → 정지 구역 반경을 영상에 맞추지 말고 1.6×(정지 시간+지연)+0.85m로 고정
2. **EN ISO 13857 상지 안전거리 (GT Engineering)** https://www.gt-engineering.it/en/technical-standards/en-iso-standards/en-iso-13857-safety-distances/safety-distances-upper-limbs/ — 상황별 팔 도달 거리 표. 위로 뻗기 저위험 2500mm, 고위험 2700mm. 표 값은 이미지라 확인 못 함. → 롤 바닥 투영선에서 0.85m를 "팔 닿는 범위"로 잡는 근거
3. **NIST SSM 구현 (PMC5117641, 2016)** https://pmc.ncbi.nlm.nih.gov/articles/PMC5117641/ — 보호 거리에 사람 위치 불확실성 Z_S 항. Z_S = 반응 시간 표준편차 × 사람 속도, 안전 목적이면 최악값. → 호모그래피 오차를 Z_S로 명시

## B. 고정 CCTV에서 발 위치를 바닥에 투영한 시스템
4. **Seong et al. 2023, Sensors (건설 장비 충돌, 국내)** https://pmc.ncbi.nlm.nih.gov/articles/PMC10610944 — YOLOv5 + 현장 구조물 기준점 DLT 호모그래피. 위험 구역 = 장비 크기 + 보행 속도×반응 시간(1m/s×1s=1m). 기준점 조건(4점 이상, 한 직선 위에 있지 않음)을 어기면 평균 위치 오차 36.95m, 지키면 0.07m. 사람 대표점 = bbox 위에서 0.914·h 아래(오차 0.076m). 208개 영상 정밀도 82.9%, 재현율 100%. **오경보 7건 중 6건은 장비 경로를 가로질러 지나간 사람** → 우리와 같은 문제
5. **Ding & Luo 2023, 단안 2D 근접 감시** https://arxiv.org/abs/2305.17931 — 금지 구역 안 = 위험, 경고 구역 안 + 다가오는 방향 = 잠재 위험, 경고 구역 안 + 멀어지는 방향 = 관심, 밖 = 안전. 방향은 몸 방향 각도의 부호로만 판정. 20m 이내 AP 75%(합성 데이터). → 규칙을 상태 기계에 그대로
6. **PETL4SD 2022 (사회적 거리두기)** https://pmc.ncbi.nlm.nih.gov/articles/PMC9734371 — 발이 가려지면 단계별 대체: 허벅지 + 이전 정강이 길이 → 몸통 아래에서 추정 → 카메라 평균 인체 비율 → bbox 하단 중앙. 머리만 보여도 접지점 추정. 위치 오차 30cm 미만. → 대체 순서 구현, 단계마다 불확실성 키우기
7. **Depth-Assisted Industrial Safety Monitoring 2025 (preprint)** https://www.preprints.org/manuscript/202511.1797 — 발 패치 깊이와 기계 구역 깊이의 차이로 억제. 알루미늄 코일 공장 오경보 34~57% 감소. ΔZ 임계값·재현율·영상 수 확인 못 함
8. **Kim et al. 2022, Sustainability** https://www.mdpi.com/2071-1050/14/13/7934 — 평면도 + OpenPose 자세로 시야 방향 안전 타원. 수치 확인 못 함

## C. 키포인트로 거리·방향·불확실성
9. **MonoLoco++ (T-ITS 2021)** https://arxiv.org/abs/2009.00984 , 코드 https://github.com/vita-epfl/monoloco — 2D 키포인트 → 거리·몸 방향·신뢰구간. 키 표준편차 약 7cm. 거리 판정 정확도 84%. **몸 방향을 넣자 위반 판정 43% → 37%(실제 36.8%)**: 방향이 오경보를 직접 줄임. → 점 대신 구간으로 판정
10. **Fang & López 2018 보행자 횡단 의도** https://arxiv.org/abs/1807.10580 — 다리·어깨 키포인트 9개 + RF. 움직임 시작 후 약 250ms에 신뢰도 0.8. → 사람이 손보다 먼저 "보행 시작과 몸 방향"으로 판단한다는 근거

## D. 소실점 없이 축척 얻기 (실패한 3개 영상 문제)
11. **원근 맵 (Zhang CVPR 2015, Shi 2019)** https://arxiv.org/abs/1807.01989 — 사람 10명 미만의 픽셀 키를 재고 평균 키 175cm로 h(y)=a·y+b 선형 피팅. 소실점 불필요. 원근이 약한 영상에서 오히려 안정. → **가장 싼 해결책**
12. **Krahnstoever & Mendonça 2005, Bayesian Autocalibration** — 발-머리 평면 호몰로지로 자동 보정. 원문 미확인
13. **Brouwers et al. 2016, 보행자 궤적 자동 보정** — 평균 오차 1.95%(시뮬레이션). 소실점 기반이라 우리 실패 영상에서는 같은 이유로 실패할 가능성
14. **Criminisi 1999, Single View Metrology** — 소실선 + 수직 소실점으로 높이 비율, 오차 전파. 180cm를 178.8cm로 측정

## 호모그래피 오차 여유 (Aside가 직접 유도, 검증 필요)
1px당 약 Z²/(f·Hc) m. 예: f=1000, Hc=4m, Z=8m → 1.6cm/px, 발목 5px 흔들림 → 약 8cm. 먼 사람일수록 제곱으로 커짐.

## 1주일 안에 가능한 것 (Aside 제안)
1. 소실점 보정 대신 4점 호모그래피를 바로 쓴다(소실점이 무한대여도 호모그래피는 정상). 롤 축 방향 축척은 롤 실제 길이, 깊이 방향은 원근 맵
2. 원근 맵 h(y)=a·y+b를 장면마다 피팅(전신 프레임 10~30개)
3. 구역 반경은 ISO 공식, 튜닝 값은 기계 정지 시간 하나로
4. 방향 게이트: 경고 구역 안에서 바닥 속도와 어깨 법선이 롤 쪽이면 감속, 그대로 정지 구역에 들어가면 정지, 롤과 평행하게 지나가면 경고만
5. 팔 뻗기는 발이 경고 구역 안일 때만 정지 근거로
6. 평가: 0.2초 단위 정밀도·재현율 + 사건 단위 재현율 + 사람 대비 지연, 원근이 약한 영상은 따로

## 실험 14 결과와 대조 (Claude 메모)
- 실험 14에서 발 게이트(S2)는 효과가 없었다. 우리 헛정지는 "가로질러 지나가는 사람"(4번 논문의 오경보 유형)이 아니라 "손 닿는 거리 안에서 평소 일하는 사람"이었기 때문이다(프레스 피더 앞 0.85m, 빨간 상의 중앙값 0.47m).
- 9번(몸 방향)과 5번(다가옴/멀어짐)은 거리 안쪽 사람에게도 쓸 수 있는 정보라 다음 후보다.
- 11번 원근 맵은 실패한 3개 영상의 보정 대안이다.
