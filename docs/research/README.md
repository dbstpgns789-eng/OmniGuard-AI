# 밤샘 조사 (Aside, 2026-10-19 밤)

질문: 카메라 한 대의 2D 겹침 때문에 생기는 헛정지를 다른 연구·제품·프로젝트는 어떻게 해결했나

- 대기열: `queue.json` (주제 10개, 하나씩 순서대로)
- 결과: `<주제 id>.md`
- 진행 방식: Claude가 Aside에 주제 하나를 보내고, 끝나면 결과를 파일로 저장한 뒤 `status`를 done으로 바꾸고 다음 주제를 보낸다
- 끊겼을 때: 새 세션에서 "docs/research/queue.json 이어서"라고 하면, status가 running인 주제부터 다시 보낸다(running은 실패로 보고 재시도, 최대 2번)
- 다 끝나면 `종합.md`에 주제별 핵심과 우리 실험에 쓸 것을 정리한다
