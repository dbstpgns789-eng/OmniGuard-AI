# 03. 손이 설비 "안으로" 들어가는지 알려 주는 단서 (Aside, 2026-10-19)

가장 중요한 공백: **팔 단축(foreshortening)이나 어깨 내밀기를 "손이 설비 안으로" 특징으로 쓰고 헛정지 수치를 보고한 논문은 찾지 못했다.** 이 단서들은 다른 분야(가리키기, 매장 선반, 협동 로봇, 인간공학)에만 있고, 공장 안전 연구는 탐지 mAP나 전체 정확도만 보고한다. 팀이 기여할 수 있는 빈자리다.

## A. 2D 포즈로 깊이 방향 알기
1. **Taylor 2000 (CVIU), 단일 영상 관절체 복원** https://www.cis.upenn.edu/~cjtaylor/PUBLICATIONS/pdfs/TaylorCVIU2000.pdf — 실제 길이 l을 알면 양 끝의 깊이 차 dZ = √(l² − (2D 길이/s)²). 어느 끝이 가까운지는 알 수 없음(해가 두 개). → 팔뚝 2D 길이 ÷ 그 작업자의 기준 길이 = r, dZ/L = √(1−r²). 부호는 장면에서 정함(롤이 작업자 뒤쪽인지). r ≈ 1 근처는 노이즈에 매우 민감해 r < 0.8만 의미 있는 신호로(Aside 추정)
2. **DeePoint (ICCV 2023)** https://arxiv.org/abs/2304.06977 — 고정 RGB 카메라의 2D 키포인트 + 관절 주변 특징 → 가리키는지와 3D 방향. 방향 오차 13.85~17.63°. 1프레임 17.08°, 15프레임(1초) 14.05°. **단순 팔꿈치→손 벡터 규칙은 확실히 나빴음.** → 고정 카메라 하나로 팔의 깊이 방향을 알 수 있고, 1초 시간 맥락이 한 프레임보다 낫다

## B. 손-물체 접촉
3. **100DOH (CVPR 2020)** https://arxiv.org/abs/2006.06669 — 손마다 상자, 접촉 상태(없음/자기/사람/휴대 물체/고정 물체). 손 AP 89.6, 손+접촉 AP 64.0. 흔한 실패: 가깝지만 닿지 않은 손. ResNet-101이라 CPU에서 느릴 것
4. **ContactHands (NeurIPS 2020)** — **포즈 키포인트만으로 만든 규칙은 34.89% mAP**, 전체 모델 57.41%. → **키포인트만으로는 접촉을 판단할 수 없다** (중요한 부정 결과)

## C. 설비 손 위험 시스템
5. **프레스 안전 감시 YOLOv8n (IEEE Access 2025)** — mAP50 99.4%, 재현율 99.9%, 95FPS, 실제로 기계 정지. 카메라가 위험 구역 자체를 비춰서 2D 문제로 만든 덕분. 헛정지 미공개
6. **Altendorf Hand Guard / Fraunhofer IPA 비교** https://www.woodworkingnetwork.com/news/woodworking-industry-news/study-finds-camera-based-safety-system-fastest-stopping-sliding — 카메라 2대, 손이 들어오면 약 0.25초에 톱날 하강. 0.2~2.0m/s에서 시험, 2m/s에서도 제때 작동. 헛정지율 미공개. → "넓은 구역 + 이른 작동", 단안 깊이가 어려워 카메라를 하나 더 둠
7. **Depth-Assisted Industrial Safety Monitoring (preprint 2025)** — 발 깊이 게이트, 오경보 34~57% 감소. **지나가는 사람에게 효과, 우리 실패 유형(손 닿는 거리 안의 작업자)과 맞지 않음** → 보고서에 대비로 한 줄

## D. 손 뻗기 의도와 시점
8. **MERL Shopping (CVPR 2016)** https://www.merl.com/publications/docs/TR2016-080.pdf — 고정 천장 카메라, 라벨: 선반으로 뻗기 / 빼기 / 손이 선반 안 / 상품 살피기 / 선반 보기(만지지 않음). mAP 80.31%. 뻗기 89.7%, 빼기 90.5%, **손이 안 65.6%(가장 어려움)**, 선반 보기 73.1%. 약 8초 맥락. → "선반에 손 넣기 vs 선반 보기"가 우리 "설비에 손 넣기 vs 앞에서 일상 작업"과 같은 구조. 라벨 체계(뻗기/안/빼기/살피기)를 빌릴 수 있다
9. **Pérez-D'Arpino & Shah 2015 (ICRA)** — 뻗기 궤적의 첫 1/3(500ms 이내)에서 목표 70% 이상 예측. → 방향은 시작 후 0.3~0.5초에 읽힘. 속도·TTC보다 자세 모양(뻗음, 단축)을. 모션캡처였을 가능성(확인 못 함)
10. **눈 추적 팔 이동 방향 예측 (IJCIM 2023)** — 시선이 손을 약 0.3초 앞섬. 실제 눈 추적기 필요
11. **GAFA (CVPR 2022)** https://github.com/kyotovision-public/dynamic-3d-gaze-from-afar — 감시 영상에서 머리·몸 방향으로 시선 추정, 오차 21.7°. → "설비를 보고 있나" 정도의 거친 판단만

## E. 일상 작업 vs 위험 개입
12. **Safe and Unsafe Behaviours 데이터셋 + Unsafe-Net (2024)** https://pmc.ncbi.nlm.nih.gov/articles/PMC11367630/ — 우리 실험 01·02·11의 데이터셋. 허가/무허가 개입 구분은 **조끼 착용 여부(외형)**이지 동작이 아님. 95.81% 정확도. → 현장에서는 "일상 vs 위험"을 기계 가동 상태·방호 상태 같은 맥락으로 정의
13. **MPED-RNN (CVPR 2019)** — 정상 골격만 학습해 재구성 못 하면 이상. AUC 0.75. → 단독 정지는 약하고 입력 특징 하나로
14. **MinerUBR (JRTIP 2025)** — 190만 파라미터, 20종 위험 행동 92.8%, CPU 138FPS. → 작은 골격 분류기는 CPU로 충분

## 1주일 안에 가능한 것 (Aside 제안)
새 모델을 넣지 말고, RTMPose 출력에서 더 뽑고 0.2초 라벨로 가벼운 분류기를 학습한다.
1. **팔 특징(반나절):** 단축 비율 r(팔뚝 2D 길이 ÷ 최근 30초의 최대 팔뚝/몸통 비율 기준), dZ/L = √(1−r²), 뻗음 e = |손목−어깨| ÷ (위팔+팔뚝 기준), 엉덩이 기준 손목 상대 속도, **가림 표시(손목이 롤 다각형 안에서 신뢰도가 떨어짐 = 손이 롤 뒤로 감)**
2. **시간 창(반나절):** 최근 5스텝(1초) 쌓기
3. **분류기(1~2일):** 로지스틱 회귀·LightGBM, 영상 하나씩 빼는 교차검증. "재현율 95% 고정에서 손 닿는 거리 안 작업자 1분당 헛정지"로 보고
4. **상태 기계에 연결(1일):** 기존 정지 규칙은 그대로, 분류기는 "팔이 나란히 움직인다"는 증거가 있을 때 경고→정지 단계만 **억제**. 가림 표시가 켜졌거나 r이 낮고 손이 롤 쪽이면 절대 억제하지 않음 → "꼿꼿한 자세" 규칙의 실수를 반복하지 않음
5. **빼기:** 손 접촉 모델(CPU에서 무겁고 키포인트만으로는 안 됨), 시선(오차 20° 이상)

**위험:** 카메라가 내려다보면 아래를 향한 팔뚝도 짧아 보인다. 팔뚝이 수십 픽셀이면 노이즈가 r을 덮는다. 첫날 기존 라벨 영상에서 r 분포부터 확인할 것.

## Claude 메모
- 실험 14의 "꼿꼿한 자세면 해제" 실패와 정확히 같은 지점을 짚는다: 해제 조건은 "안전 증거"만으로 걸지 말고, 위험 증거(가림, 단축)가 있으면 해제를 막아야 한다.
- 가림 표시(손목 신뢰도가 롤 다각형 안에서 떨어짐)는 실험 03·07에서 본 "위험한 순간에 관절이 사라진다"를 거꾸로 신호로 쓰는 아이디어다. 기존 포즈 파일만으로 바로 시험할 수 있다.
- MERL의 라벨 체계는 채우 님과의 두 번째 판단표 양식에 참고할 만하다.
