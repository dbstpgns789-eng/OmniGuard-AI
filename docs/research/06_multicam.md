# 06. 저비용 카메라 2~3대 결합 (Aside, 2026-10-19)

핵심: "카메라 2대 AND로 회전체 앞 헛정지가 X% 줄었다"를 직접 보고한 자료는 없다. 인접 분야(행동 인식, 사람 검출)에서 카메라를 늘리면 오탐이 줄고 재현율이 오른다는 방향은 일치한다.

## A. 상용
1. **Altendorf HAND GUARD + Fraunhofer IPA** https://www.altendorf.com/en-us/machines/altendorf-hand-guard — 캐리지 위 카메라 2대, 동기화·상태 감시. 1/4초 하강, 재가동 10초. 0.2~2.0m/s 시험, 시험체 손상을 모든 시험에서 피한 건 카메라 방식뿐. 개선판 AI 데이터 확대로 오작동 "크게 감소"(수치 없음), 레이저로 바닥에 구역 표시. → 구역을 바닥에 물리적으로 표시(테이프), 정지 후 빠른 재가동
2. **Pilz SafetyEYE** — 카메라 3대 스테레오, 위에서 내려다봄, 7.5m. 최소 크기 이상만 검출, 경고 구역 감속 → 가장 가까운 구역 비상정지. → 우리 4단계가 업계 표준과 같은 구조
3. **Veo Robotics FreeMove** — 3D ToF 여러 대를 하나로 합침. **공간을 비어 있음/점유/모름 3상태로, 보이지 않는 곳(모름)은 확인될 때까지 점유로 취급.** PL d. → 한 카메라에서 손이 사라지면 "안 보이니 안전"이 아니라 "모름 → 감속"
4. **SICK safeVisionary2** — ToF, 손 20mm 검출, 응답 55ms 이상. multiple sampling(몇 번 검출돼야 반응)을 높이면 헛정지 감소, 응답시간 증가. → N-of-M 시간 확인, 늘어난 지연은 안전거리에 반영

## B. 1대 vs 여러 대 수치
5. **Depth-Assisted Industrial Safety Monitoring (preprint 2025)** — 단안 깊이 보조, 오경보 34~57% 감소 → **2카메라 결과가 넘어야 할 기준선**
6. **건설 HRC 다중 카메라 행동 인식 (Sensors 2023)** https://pmc.ncbi.nlm.nih.gov/articles/PMC10422633/ — 카메라별 2D 관절 → 파티클 필터 3D → LSTM. **정확도 1대 82%, 2대 92%, 3대 97%, 4대 98%.** 무릎꿇기 정밀도 1대 0.63 → 2대 0.95, 사다리 재현율 0.71 → 0.90. GPU 없는 i7 노트북. → "1대에서 2대로 가면 오탐과 미탐이 동시에 준다"의 가장 직접적인 수치, CPU 조건도 같음
7. **Fleuret et al. 2008 (TPAMI), 확률적 점유 지도** — 카메라 4대, 6명 추적, 심한 가림에서도 FP/FN 없음, 영상 20%를 잃어도 성능 저하 없음
8. **MVPose (CVPR 2019)** https://github.com/zju3dv/mvpose — 뷰 간 에피폴라 거리로 2D 포즈 매칭, **다른 뷰에서 짝이 없는 검출은 오검출로 버림** → AND 투표의 원리
9. **카메라 배치 최적화 (Sensors 2022)** https://pmc.ncbi.nlm.nih.gov/articles/PMC9823859/ — 최적 배치 커버리지 1대 91.9%, 2대 98.8%, **엔지니어 직관 배치는 55%, 72%.** → 측면 카메라 위치를 직관으로 정하지 말고 맞물림부가 두 화면 모두에 들어오는지 먼저 확인

## C. CPU 오픈소스
10. **Pose2Sim** https://github.com/perfanalytics/pose2sim — RTMPose 기본, openvino/onnxruntime. 동기화: 카메라마다 키포인트 평균 수직속도의 상호상관으로 시간 오프셋(박수·플래시도 가능). 삼각측량: 신뢰도 0.3 이상, 재투영오차 15px 넘으면 카메라 하나씩 빼며 재시도, 최소 2대. 캘리브레이션 "scene" 방식: 장면에서 10개 이상 점의 3D 좌표 실측(**문서 예시에 "treadmill dimensions"**), 외부 파라미터 오차 1cm 이하 권장·2.5cm 허용. 좌우 스왑 처리는 미구현. → 가장 직접적으로 재사용 가능
11. **Anipose / aniposelib** https://anipose.readthedocs.io/en/latest/aniposelib-api.html — ChArUco(부분 가림에도 검출) 권장, triangulate_ransac(min_cams=2), 재투영 기본 15px
12. **FreeMoCap** https://docs.freemocap.org/freemocap/docs/guides/camera-setup/ — 웹캠·폰 2대 이상, CPU 설계. 2대는 "Basic", 3~4대 "Good". 720p 30fps 이상, **노출·초점·화이트밸런스 수동 고정**, 소프트웨어 동기화, 세션 30분 미만
13. **EasyMocap 캘리브레이션 + OpenCV** — 바닥에 놓은 체커보드 한 장으로 외부 파라미터, 큐브를 그려 검증. ChArUco 권장. triangulatePoints(DLT), findFundamentalMat·computeCorrespondEpilines → 보드를 러닝머신 데크에 평평하게 놓고 solvePnP하면 "데크 = 높이 0" 좌표계
14. **폰 동기화 libsoftwaresync / RecSync-android** https://github.com/MobileRoboticsSkoltech/RecSync-android — Wi-Fi로 시계 맞춤, 250µs 미만, 드리프트 분당 1.2ms 미만. Android Camera2 API 필요(기종 호환 확인 못 함)
- 참고: Angleraud 2024 — 두 영역에서 동시에 검출될 때만 인정하자 손목 하나로 인한 오탐에 강해짐(AND 규칙, 수치 확인 못 함)

## 1주 안에 할 것 (Aside 제안, 폰·웹캠 2대, CPU)
**배치:** 정면 + 측면 약 90°, 둘 다 끝 롤러(맞물림부)가 화면 중앙. 720p 30fps(가능하면 60), 노출·초점 고정. 측면 카메라는 "손이 롤 앞인지 뒤인지"가 보이는 위치.

**동기화(비용 순):** ① 녹화 시작 때 박수 + 폰 플래시를 두 화면에 담고 손목을 위아래로 3번 크게 흔듦 → 손목 수직속도 상호상관으로 오프셋 ② Android 2대면 RecSync ③ PC 웹캠은 호스트 시각으로 짝짓고 반 프레임(16.7ms) 넘게 어긋난 쌍은 버림. 손 2m/s일 때 한 프레임(33ms) 어긋나면 6.7cm 오차, 0.2m/s면 0.7cm.

**캘리브레이션(반나절):** A3 ChArUco를 단단한 판에 붙여 카메라별 20~30장(내부) → 보드를 데크에 평평히 놓고 solvePnP(외부) 또는 롤러 끝·프레임 모서리 등 10점 이상 줄자 실측. 보드 코너를 삼각측량해 칸 크기 확인, 1cm 이하 목표. **위험구역은 화면에 손으로 그리지 말고 3D로 정의**(롤 축 선분 + 반경 + 여유) → 각 화면의 다각형은 자동 투영.

**결합 규칙 비교 순서**
| 규칙 | 정지 조건 | 예상 |
|---|---|---|
| R0 정면 하나 | 손이 정면 다각형 안 | 기준선 |
| R1 2D-AND | 같은 손이 두 화면 다각형 모두 안 | 직교 배치면 두 다각형의 교집합 ≈ 3D 구역, 2D 겹침 헛정지가 가장 크게 감소. 한쪽에서 손을 놓치면 재현율 하락 |
| R2 3D 삼각측량 | 손목 3D와 롤 축 거리 < 임계값, 재투영 ≤ 15px | 경계가 정확, 거리 단계가 자연스러움 |
| R3 = R2 + 손실 처리 | 아래 | 재현율 회복 |
**시작은 R1 + R3 손실 처리**(캘리브레이션 없이 하루), 보정이 끝나면 R2로.

**세부 규칙(R3)**
- 손 = 손목 + 0.4·(손목 − 팔꿈치) (경험값)
- 측면 화면에서 좌우가 자주 바뀜 → 4조합 모두 삼각측량해 재투영오차 최소 조합
- 보정 없이 에피폴라 검사: 관절 대응점 1분치로 F 추정, 손목-에피폴라선 거리 10~20px 안이면 같은 손(추정값)
- **한 화면에서 손을 잃으면:** 보이는 화면에서 손이 구역 안이면 "모름 → 감속". 직전 3D 위치를 등속으로 최대 0.2초 예측해 정지 구역이면 정지. 모름이 0.4초 넘게 이어지면 정지
- 정지 진입 3프레임 중 2, 해제는 두 화면 모두 깨끗한 상태 0.6초 이상

**평가:** R0~R3을 같은 영상에서 분당 헛정지, 정지 정밀도·재현율, 첫 정지까지 지연. 스트레스 시험: 측면 카메라 가리기, 33·66ms 동기 오차 주입, 카메라 1cm/2° 이동. 기준선은 단안 깊이 보조의 −34~57%.

연구용 프로토타입이고 안전 등급이 아니다.

## Claude 메모
- 촬영 계획에 바로 반영할 것: ChArUco 보드(A3 인쇄) 준비, 데크 위 보드 촬영, 노출·초점 고정, 박수 + 플래시 + 손목 흔들기 동기화, 맞물림부가 두 화면 중앙.
- R1(2D-AND)은 지금의 판단기 코드에 화면 하나를 더하는 수준이라 촬영 직후 바로 돌릴 수 있다.
- "모름 → 감속"은 실험 14의 "발이 안 보이면 감속"과 같은 원리다.
