## 이번 주에 가져다 쓸 것 (Aside 제안)
1. **비대칭 상태 기계:** 진입은 빠르게(정상→경고 1프레임, 경고→정지는 리키 버킷 +2/−1, 임계 4~6), 해제는 느리게(손이 구역 밖에 2.5초 이상 + 공간 히스테리시스 + 수동 재기동). 확인 프레임 0.2초당 정지 거리 400mm 증가 → 확인은 정지 진입에만 최소로, 감속은 바로
2. **"모름" 상태:** 손목·발목 conf가 떨어지거나 프레임이 끊기면 감속. 단 #19에서 짧은 정지의 최대 원인이 이것이니 따로 세서 분리 보고
3. **몸 크기 정규화:** #3의 "5×폭, 1.5×높이"를 RTMPose 어깨폭·몸통 길이로
4. **접근 속도 게이트 + 특이도 시나리오:** 러닝머신 촬영에 "작업면을 가로지르는 손", "급후퇴", "가동 반경 안 정상 작업"을 멈추면 안 되는 시나리오로
5. **헛정지 세는 방식:** 에피소드 병합(간격 0.5초, 최소 지속 0.5초)으로 다시 세서, 병합 기준에 따라 수치가 얼마나 달라지는지 표로
6. **작은 도구:** supervision ViewTransformer(MIT), ignore zone(경고 단계에서만, 정지 구역에는 쓰지 말 것), 프레임 타임아웃 → 정지
