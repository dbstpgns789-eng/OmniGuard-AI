# 05. 평가 데이터셋과 안전한 연기 촬영 (Aside, 2026-10-19)

요약: 0.2초마다 "지금 멈춰야 하나"를 라벨링한 공개 벤치마크는 없고, 공장 설비에서 리드타임·헛정지율을 보고한 곳도 없다. 가장 쓸모 있는 것은 **iSafetyBench**(실제 끼임 클립), **AI Hub 스마트 제조 시설 안전 감시 데이터**(끼임 2,000개), **Safe and Unsafe Behaviours 나머지**(설비 바로 옆 정상 작업). CHICO는 2D 겹침과 실제 접촉의 차이를 직접 잴 수 있는 유일한 데이터셋.

## A. 데이터셋 (우선순위 순)
1. **Safe and Unsafe Behaviours (2024)** https://huggingface.co/datasets/Voxel51/Safe_and_Unsafe_Behaviours — 691클립, 8클래스, 1080p 24fps, 고정 CCTV 2대, CC BY 4.0. 클립 단위 라벨. 끼임 사고 없음. 논문 한계 절에 "2D 투영상 차도 보행자가 보도 위로 보임" → 우리 2D 겹침과 같은 문제. → **Authorized Intervention과 Panel Cover 클립 전부를 "정상인데 설비에 붙어 있는" 하드 네거티브로 넣어 헛정지 측정** (지금은 14개만 씀)
2. **iSafetyBench (ICCV-W 2025)** https://huggingface.co/datasets/raiyaanabdullah/isafety-bench — 1,100클립, YouTube 출처, CC BY-NC-SA 4.0. 위험 클립 중 끼임·압착(몸이 기계에 끌려 들어감 13, 컨베이어에 발 끼임 13, 닫히는 기계 사이 3, 셔츠 2, 머리카락 1) + 기계 오조작 = **42클립**, 원본 YouTube 영상은 7개뿐이라 겹침 많음. `0QHQ2nmdE78_clip0` trim 2→4→7→8은 "가동 중 롤 조정 → 롤 위로 손 → 손 넣음 → 말림" 순서(우리 실험 10 영상). VLM 제로샷 최고 40.3%. → 끼임 42클립을 0.2초 단위로 다시 라벨링. 기존 영상과 중복 확인 먼저
3. **AI Hub 스마트 제조 시설 안전 감시 (71679)** https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=71679 — 일반·열화상 CCTV 20,000개, **끼임 2,000개**, 맞음 1,700, 미사고 500. 1080p, 주간/야간. 영상 단위 이벤트 + 사람 분할 + 설비 상자. 구간 라벨 여부·연출 여부 확인 못 함(규모상 연출 추정). 내국인만 신청, 승인 후 다운로드. → 국내 최대 끼임 영상, 샘플부터
4. **AI Hub 건설 현장 위험 상태 판단 (71407)** — 협착 40,000장. 우선순위 낮음, 시나리오 정의 참고
5. **LAMIS (2024)** https://github.com/navalkishoremehta95/IAR-NET — 선반(회전기계) 작업 2,214클립, 17행동. Google Form 신청. → 회전체 옆 정상 작업으로 헛정지 측정, 오늘 신청 권장
6. **CHICO (ECCV 2022)** https://github.com/AlessioSam/CHICO-PoseForecasting — 작업자 20명, 카메라 3대, 3D 포즈, **실제 충돌 226건**(협동로봇 토크 센서). 충돌 검출 F1 0.64. → 한 카메라 2D에서는 겹치는데 3D로는 떨어진 프레임 수를 직접 셀 수 있음. 핵심 문제 정량화에 가장 적합
7. **IPAD (2024)** https://ljf1113.github.io/IPAD_VAD — 산업 장비 16종, 597,979프레임, 프레임 단위 이상 라벨. 사람 거의 없음. → 사람 없는 가동 설비에서 유령 검출(기둥을 사람으로) 헛정지 검사
8. **Industrial Safety Violation Detection (arXiv 2412.05531)** — 실제 감시 영상 2,900클립, PPE 위주, 공개 여부 확인 못 함
9. **InHARD (2020)** https://github.com/vhavard/InHARD — 200만 프레임, 모션캡처 스켈레톤. 위험 없음. → 바쁜 손 작업 하드 네거티브
10. **HA-ViD (NeurIPS D&B 2023)** — 멀티뷰 3,222영상. 위험 없음
11. **IKEA ASM / OpenPack / MECCANO** — 조립·물류, 기계 없음, 우선순위 낮음
12. **Construction Meta Action (2023)** — Baidu 배포, 우선순위 낮음
13. **"기계 끼임" CCTV 모음** — YouTube 모음집이 대부분, 라벨·라이선스 없음. 라벨 붙은 공개본은 iSafetyBench가 사실상 유일

## B. 지표 참고
- 산업 데이터셋에서 리드타임이나 시간당 헛정지를 보고한 곳은 없음. 교통사고 예측 지표를 빌린다.
- DAD: 사고 620 + 정상 1,130, 5초 영상. 지표 AP, mTTA(평균 사고 전 경보 시간), TTA@R80. LATTE: AP 89.74%, mTTA 4.49초.
- 오경보율이 λ 이하일 때만 재현율·TTA 평가 → "헛정지율 X 이하에서 재현율과 리드타임"

## C. 안전한 연출 기준
- ISO 13855 손 2000mm/s, 보행 1600mm/s. 정지 시간 0.3초면 손은 60cm 이동
- IEC TS 61496-4-3(스테레오 비전 보호장치): 검출 능력 최대 200mm, 시험편 규격은 유료 본문이라 확인 못 함
- 대리 신체: SawStop은 핫도그, NHTSA는 관절 있는 보행자 마네킹
- iSafetyBench 저자: 기존 위험 데이터셋은 대부분 연출 → 연출 데이터는 실제 영상과 분리해 보고

## 1주 안에 할 것 (Aside 제안)
**바로 받기:** Safe and Unsafe Behaviours 나머지 개입·패널 클립(하드 네거티브), iSafetyBench 끼임 42클립(중복 제거 후 사고 테스트셋), CHICO(2D 겹침 정량화), IPAD(유령 검출)
**오늘 신청:** AI Hub 71679, LAMIS
**라벨·지표:** 0.2초 "지금 멈춰야 하나" 2인 라벨링 + 일치도 κ. 이벤트 재현율, 리드타임(접촉 시각 − 첫 정지), 정상 영상 시간당 헛정지

**러닝머신 + 카메라 2대 연출**
- 안전: 러닝머신 끝 롤러는 실제 끼임점, 사람 손은 절대 가까이 가지 않는다. 판단기는 포즈와 경계선만 쓰므로 접촉·말림 장면은 벨트를 끄고 찍어도 된다. 벨트를 켤 때는 최저 속도, 안전키 끈은 보조자가. 머리 묶고 소매 걷기. 롤 위치에 폼 롤이나 PVC 관으로 "가짜 롤"
- 카메라 A(평가용 CCTV): 높이 2.5~3m, 30~45° 내려다보는 광각. **일부러 깊이가 헷갈리는 각도**
- 카메라 B(정답 측정용): A와 직교하는 측면·위쪽. 롤에 ArUco 마커, 바닥에 10cm 간격 테이프로 손목-롤 실제 거리 계산 → 객관적 정답. LED 점멸·박수로 동기화, 30fps를 5Hz로
- 시나리오: ① 겹쳐 보이지만 먼 정상 작업(프레임 닦기, 점검, 롤 뒤로 지나가기, 공구 집기) ② 실제 접근(0.3m/s, 1m/s 손 뻗기, 멈춤선은 롤 30cm 앞) ③ 빠른 반사적 손 뻗기(2m/s)는 마네킹 팔을 막대에 달아 ④ 말림 전조: 소매·장갑·걸레가 끌려가는 장면을 벨트 끈 상태에서 숨긴 실로 당겨 연출
- 변인: 옷 색(빨간 셔츠 포함), 조명, 가림(두 번째 사람, 상자), 카메라 높이, 배우 3~5명, 정상과 위험을 비슷한 수로
- 판정 기준: ISO 13855 기준 T 이상 남기고 정지를 냈는가
