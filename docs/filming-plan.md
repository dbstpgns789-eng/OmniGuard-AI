# 러닝머신 시험 영상 촬영 계획

러닝머신을 컨베이어로 보고, 뒤쪽 롤러를 회전체(위험한계)로 둔다. 목적은 변인을 통제한 평가 데이터를 만드는 것이다: 고정 카메라, 줄자로 잰 기준선, 촬영 전에 정한 장면별 정답.

- 시험 촬영: 10-17(토), 세훈 혼자. 장면 1·4·5·6만
- 본 촬영: 10-20(화), 학교 헬스장, 세훈·채우. 8장면 × 5회 = 40개

## 준비물

| 물건 | 용도 |
|---|---|
| 휴대폰 + 삼각대 **2대 (필수)** | 카메라 A(옆)와 B(뒤쪽 위 45°). 두 대가 있어야 3D 위치를 계산할 수 있다. 삼각대가 하나뿐이면 B는 선반이나 벽에 고정해도 된다 |
| 줄자 (3m 이상) | 기준선 거리 측정 |
| 색 테이프 | 바닥 기준선 표시 |
| 상자 1~2개 | 장면 2·3·8의 "물건" |
| 스톱워치 (휴대폰) | 벨트 정지 시간 측정 보조 |
| 이 문서의 정답표 (인쇄 또는 휴대폰) | 촬영하면서 바로 기록 |

## 안전 규칙

- 벨트가 돌 때는 뒤쪽 롤러 50cm 안으로 손을 가져가지 않는다.
- 손을 롤러 쪽으로 뻗는 장면(5·6·7·8)은 **전원을 끄고** 찍는다. 가동 여부는 정답표에 따로 적는다.
- 헐렁한 소매, 끈, 장갑은 피한다. 헬스장 직원에게 촬영 허락을 받는다.

## 카메라 배치

**카메라 A (주 카메라): 러닝머신 옆, 롤러 축 방향**

```
        (위에서 본 그림)
                     ┌─────────── 러닝머신 ───────────┐
     앞(콘솔)        │                                │ ● 뒤쪽 롤러
                     └────────────────────────────────┘
                                      ↑ 2~3m
                                   [카메라 A]  높이 약 1m, 살짝 아래로
```

- 카메라를 러닝머신 **옆면**에 수직으로 두고, 화면에 뒤쪽 롤러와 그 뒤 바닥 1.5m가 모두 들어오게 한다.
- 이렇게 두면 사람이 뒤에서 롤러로 다가가는 움직임이 화면 좌우 방향이 되어, 화면 거리와 실제 거리가 거의 비례한다(실험 04·05의 깊이 문제를 피한다).
- 가로 화면, 1080p, 30fps 이상. 노출·초점 고정(화면을 길게 눌러 잠금). 비행기 모드.

**카메라 B (필수, 2026-10-17 변경): 뒤쪽 위에서 비스듬히 (약 45°)**
- 실제 공장 CCTV와 비슷한 시점이다. 이 화면 하나로만 판단하면 공장 영상처럼 "롤러 앞에 서 있기만 해도 겹쳐 보이는" 문제가 생긴다(실험 04~08).
- 카메라 A와 B를 함께 쓰면 손목의 **3D 위치**를 계산할 수 있다(삼각측량). 시연의 핵심 장면: 같은 장면을 B 하나로 판단한 결과(헛정지)와 A+B로 판단한 결과(손이 다가갈 때만 정지)를 나란히 보여 준다.

### 두 카메라를 맞추기 위해 꼭 지킬 것

1. **바닥 기준선(테이프)이 두 화면 모두에 보이게** 둔다. 두 화면에서 같은 점을 찾아 카메라 위치를 계산하는 데 쓴다.
2. 테이프 교차점(롤러 아래 0, 0.5m, 1.0m 지점의 양 끝)처럼 **위치를 아는 점을 6개 이상** 만든다. 러닝머신 모서리 4곳도 기준점이 된다(가로·세로 길이를 줄자로 잰다).
3. 두 카메라 모두 **같은 프레임 수(30fps)**, 가로 화면, 녹화 중 위치와 줌을 바꾸지 않는다.
4. 장면마다 시작할 때 **손뼉을 한 번** 친다. 두 영상의 시간을 맞추는 기준이다.
5. 촬영 전후에 **사람 없이 5초씩** 찍는다(배경과 롤러 위치 확인용).

## 바닥 기준선 (거리 축척용)

뒤쪽 롤러 축의 바로 아래 바닥을 0으로 두고, 러닝머신 뒤쪽으로 줄자를 대서 테이프를 붙인다.

| 테이프 | 롤러에서 거리 |
|---|---|
| 1 | 0.5m |
| 2 | 1.0m |
| 3 | 1.5m |
| 4 | 2.0m |

- 이 선들은 정지·감속 구역 자체가 아니라 **화면 픽셀을 미터로 바꾸는 기준**이다. 구역 경계는 안전 거리 공식으로 나중에 소프트웨어에서 정한다.
- 롤러 높이(바닥에서 롤러 중심까지)와 벨트 폭도 줄자로 재서 적는다.

## 벨트 정지 시간 측정 (안전 거리 계산용)

1. 카메라 A로 녹화를 켠 채, 벨트를 시속 3km와 6km로 각각 돌린다.
2. 정지 버튼을 누르는 순간 손이 화면에 보이게 하고, 벨트가 완전히 멈출 때까지 찍는다.
3. 속도마다 3번씩. 프레임 단위로 재므로 스톱워치는 보조용이다.

이 값으로 안전 거리 S = 2,000mm/s × (시스템 지연 + 벨트 정지 시간)을 계산한다.

## 장면과 정답표

모든 장면은 **화면 밖이나 2m 선 바깥에서 시작**하고, 시작할 때 손뼉을 한 번 쳐서 영상 시작점을 표시한다. 한 장면은 약 10초.

| # | 장면 | 가동 | 정답 단계 | 비고 |
|---|---|---|---|---|
| 1 | 러닝머신 옆을 지나감 | 켬 | 반응 없음 | |
| 2 | 벨트 위로 상자가 지나가고, 앞쪽에서 상자를 올려놓음 | 켬 | 반응 없음 | |
| 3 | 앞쪽에서 벨트 위 상자를 집어 듦 | 켬 | 반응 없음 | |
| 4 | 뒤쪽 롤러 가까이(1.0~1.5m) 다가가 섬 | 켬 | 주의 | |
| 5 | 숙여서 뒤쪽 롤러 쪽으로 손을 뻗음 (닿지 않음) | **끔** | 감속 | |
| 6 | 손을 롤러에 닿기 직전까지 넣음 | **끔** | 정지 | 손이 롤러에 가장 가까워진 순간을 나중에 표시 |
| 7 | 정지 상태에서 롤러 청소 | **끔** (정답표도 정지 중) | 반응 없음 | |
| 8 | 2인: 한 명은 앞쪽에서 상자를 올리고, 다른 한 명이 뒤에서 손을 넣음 | **끔** | 정지 (손 넣은 사람만) | 화요일 |

## 시험 촬영(토요일)에서 확인할 것

- 카메라 A 화면에 롤러, 기준선 4개, 사람의 몸 전체가 함께 들어오는가
- 손목이 화면에서 충분히 크게 보이는가 (사람 키가 화면 높이의 40% 이상이면 좋다)
- 벨트 정지 시간 측정
- 장면 1·4·5·6 각 2회
