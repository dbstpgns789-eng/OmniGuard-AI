# 조사: 카메라로 위험구역을 감시할 때 헛정지를 줄이는 방법 (2026-10-18, Aside)

질문: 카메라 한 대(또는 저렴한 여러 대)로, 헛정지를 줄이면서 "지금 멈춰야 한다"는 판단은 일찍 내는 방법을 다른 연구·제품은 어떻게 해결했나?

## 핵심 결론

1. 2D 겹침 헛정지를 줄인 방법으로 효과가 보고된 것은 네 가지다. 손 대신 **발(바닥 위치)**로 판정, **이동 방향** 조건, **여러 프레임 확인**, 애매하면 **정지 대신 감속**.
2. 상용 업체도 롤 맞물림부의 "확실한 정지"는 일반 CCTV로 하지 않는다. CCTV는 경고, 정지는 설비 가까이 단 깊이 카메라(Intenseye) 또는 카메라 2대(Altendorf)로 나눈다. 우리 결과(2D 한 대로는 정지 헛정지를 못 줄임)와 맞는다.
3. 포즈 기반 판단은 현행 안전장치 인증(IEC TS 61496-4-3) 범위 밖이다. 발표·보고서에서는 "보조 시스템"으로 부르는 것이 맞다(IFA도 Altendorf를 보조 시스템으로 평가).
4. 국내에는 아직 AI 인체감지 시스템의 오경보율 공식 기준이 없다. 고용노동부·안전보건공단이 2026-11-27까지 용역으로 최소 성능기준을 마련할 계획이다.

## 우리 평가 지표 제안

- 프레임 단위 헛정지 비율 대신: **정상 영상 1시간당 헛정지 횟수**, **사람 정지 구간 재현율**, **판단기 첫 정지 - 사람 첫 정지 분포**
- "1시간당 헛정지 ≤ X" 상한 아래에서 재현율을 보고
- 감속이 사람 정지 구간을 얼마나 덮는지 따로 집계
- 영상 하나씩 빼는 교차검증

## Aside가 제안한 순위 (1주, CPU, 사전학습 모델)

1. **발 기준 도달 범위 게이트:** 발목 중점을 바닥 좌표로 바꿔 롤의 바닥 투영까지 거리 d_foot을 잼. 정지 = 손 겹침 AND d_foot ≤ 0.85m(팔 길이) + 거리 비례 여유. 발이 가려지면 감속
2. **애매한 겹침은 감속:** 겹치지만 발이 도달 범위 밖이거나 안 보이면 정지 대신 감속
3. **바닥 좌표 접근 속도·방향으로 조기 경고:** 발의 바닥 속도(m/s)와 어깨 방향. 경고 반경 = 1.6m/s × T + 0.85m (표준에서 계산)
4. **시간 확인 + 해제 조건:** 정지 2-of-3, 해제는 1초 유지 + 발이 도달 범위 + 0.3m 밖. 단독으로는 "롤 앞에 계속 서 있음"에 효과 작음
5. **정규화 특징 + 작은 분류기:** d_foot, 바닥 속도, 몸 방향, 겹친 비율로 0.5초 창 로지스틱 회귀·RF, 영상 하나씩 빼고 학습

```
foot = H(mid(L_ankle, R_ankle))          # 바닥 좌표 (m)
d = dist(foot, roll_footprint);  v_r = -EMA(dd/dt, 0.6s)
reach = d <= 0.85 + k*cam_dist           # ISO 13855 C + 호모그래피 오차 여유
STOP  : wrist_overlap & reach & roll_running   (2 of last 3 steps)
SLOW  : wrist_overlap & (!reach | feet_occluded)
        | d < 1.6*T + 0.85 & v_r > 0.3 & facing_roll
WARN  : d < warn_band | (v_r > 0.2 & facing_roll)
RELEASE: 1.0s 유지 & d > 0.85 + 0.3
```

## 주의

- 벤더 수치(iFactory, Flagman 등)는 마케팅 자료라 검증되지 않았다.
- DeepMonitor·호이스팅 논문은 초록과 발췌만 확인했다.
- 바닥 좌표를 미터로 쓰려면 바닥의 실제 길이 기준이 필요하다. 인터넷 사고 영상에는 없으므로, 기존 영상에서는 몸통 길이 단위로 대신하고, 러닝머신 촬영에서는 바닥 테이프(0.5~2m)로 미터를 잡는다.
