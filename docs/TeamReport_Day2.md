# IC-PBL 팀활동보고서 (최종 프로젝트 2일 차)

## 미팅 개요

| 항목 | 내용 |
|------|------|
| 팀이름 | OmniGuard-AI |
| 일시 | 2026-10-19 ~ 2026-10-20 (팀 미팅 2026-10-20) |
| 참석자 | 윤세훈, 이채우 |
| 문제해결과정 | **① 문제 확인:** 카메라 한 대의 2D 화면에서는 롤 앞에 서 있기만 해도 위험한계와 겹쳐 보여, 판단기가 평소 작업 중에도 자주 멈춤(헛정지)<br>**② 원인 분석:** 헛정지가 난 장면마다 원인이 된 관절을 기록 → 9번 모두 상체가 화면에서 겹쳐 보인 것이고, 발·무릎은 0번<br>**③ 해결 시도:** 규칙의 세부 값 6개로 336가지 조합을 그리드 서치(헛정지 0번인 "조용한 안"), 원인 관절에 맞춘 규칙 추가(헛정지 9번 → 1번, 사고 4/4 유지)<br>**④ 새 문제:** 이 개선이 모두 개발 데이터에서 얻은 것이라, 처음 보는 사고에서도 통하는지 알 수 없음 → 과적합 우려<br>**⑤ 검증 설계:** 시험 전에 판단기 3개를 고정하고, 새로 모은 사고 19건을 시험 10건·검증 9건으로 무작위로 나눠, 시험 데이터는 한 번만 채점하기로 함 |
| 본 미팅의 주요활동 | 데모 테스트, 규칙 다듬기 결과 공유, 시험 데이터 구축과 판단기 고정, VLM 재검증과 3D 방식의 개선 방안 논의 |

## 진행 사항

| 항목 | 내용 |
|------|------|
| 이번 미팅에서 한 일(활동 내용) | **판단기 개선 실험(세훈)**<br>• 판단자 2명(세훈·채우)이 따로 정답지를 적어 정답의 신뢰도 확인. 안내문에 "정지 = 예방 시점"이 빠져 한 사람이 한 칸 낮게 판단한 것을 찾아 보정<br>• 사람 윤곽(YOLO11n-seg)으로 헐렁한 옷이 롤에 다가가는 순간을 관절보다 2.5초 일찍 잡음<br>• 팔이 짧아 보이는 단서, 가림 단서는 효과 없음(화면만으로 롤 쪽으로 뻗는 것과 기계 위에 손을 얹는 것이 구별되지 않음)<br>• 336가지 조합 그리드 서치, 헛정지 원인 관절 분석으로 규칙 개선<br>**VLM 판정 실험(채우)**<br>• imajev-4b로 사고 영상 5개 374장 판정: 장면당 평균 0.133초로 0.3초 목표를 모두 만족했지만, 판단 보류가 25.1%이고 정지는 3개 장면에서만 나옴<br>**데이터와 조사**<br>• 시험용 사고 영상 19건 수집(웹 영상 6개 + 유튜브 사고 채널 화면 녹화 13개)<br>• 국내 안전 기준, 2D 헛정지 해결 사례, 공개 데이터셋, 단안 깊이 모델 조사 |
| 이번 미팅에서 한 일(조치 사항) | • 시험 전 판단기 3개 고정: 원칙 규칙, 규칙 4, 조용한 안<br>• 사고 19건을 무작위로 시험 10건·검증 9건으로 분할(결과를 보기 전에 기록)<br>• 판단 단계를 정상·주의·감속·정지 4단계에서 정상·주의·정지 3단계로 줄임<br>• 라벨 분담: 정답지는 세훈·채우, 위험한계 그리기는 세훈<br>• 1차 판단 뒤 VLM으로 재검증하는 방식(채우)과 3D 정보로 위험을 판단하는 방식(세훈)을 각각 검토하기로 함 |
| 논의 사항 | • 개발 데이터에서 다듬은 규칙이 처음 보는 사고에서도 통할지(과적합)<br>• VLM을 추가하면 판정 성능과 처리 시간이 어떻게 바뀌는지<br>• 3D 방식의 구현 가능성과 필요한 데이터·장비(깊이 모델, 카메라 2대)<br>• 데모 영상은 빨간 상의 사고를 포함해 고르고, 발표는 심사 기준별로 "왜"와 인사이트를 중심으로 구성 |
