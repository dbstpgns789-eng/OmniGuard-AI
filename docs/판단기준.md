# 판단표 작성 기준 (판단자용)

실험 15에서 같은 안내문을 받고도 한 사람은 예방 시점을, 다른 사람은 사고 발생 시점을 "정지"로 골랐다. 앞으로 판단표를 받을 때는 이 문서를 함께 준다.

2026-10-20 회의: 단계를 **정상 / 주의 / 정지 3개로 줄였다.** 예전 "감속"에 해당하는 장면은 "주의"로 적는다. 판단기는 4단계를 그대로 내고, 채점할 때 판단기의 감속을 주의로 합쳐 비교한다.

## 질문
"이 CCTV를 보며 기계 정지 버튼을 쥐고 있다면, **사고를 막으려면** 지금 무엇을 해야 하나?"
사고가 났는지를 묻는 것이 아니다. 사고가 나기 **전에** 어떻게 대응해야 하는지를 묻는다.

## 단계
| 단계 | 기준 | 예 |
|---|---|---|
| 정상 | 회전체와 떨어져 있고, 다가가지 않음 | 설비 옆을 지나감, 떨어진 곳에서 작업 |
| 주의 | 회전체 가까이 있거나 다가가는 중, 또는 곧 위험한 행동을 할 것 같음 | 설비 쪽으로 걸어감, 설비 앞에 섬, 롤 쪽으로 손을 뻗기 시작함, 몸을 숙임, 반 발자국 거리 |
| 정지 | 지금 멈추지 않으면 1초 안에 손·몸·옷·머리카락이 회전체에 닿을 수 있음. **이미 닿았으면 무조건 정지** | 손이 롤 위에 얹힘, 헐렁한 옷이 롤에 걸릴 듯한 거리, 빨려 들어감 |

## 적는 법
- 판단이 바뀌는 프레임에만 적어도 된다. 빈칸은 바로 앞 판단이 이어진다.
- 사고 이후나 모자이크로 판단할 수 없는 구간은 비워 둔다(마지막 판단 뒤의 빈칸은 채점에서 뺀다).
- **회전체에 닿음:** 몸의 일부(옷 포함)가 **회전하는 롤 표면**에 닿으면 Y. 벨트 위에 서 있거나 설비 몸체를 만지는 것은 N. 화면으로 알 수 없으면 "모름".
- 메모에는 왜 그 단계인지 짧게 적는다(예: "손을 뻗음", "옷이 걸릴 듯한 거리").
