# 시도 기록: 사고 직전 정지율을 지키면서 헛정지 줄이기

목표(2026-10-20 세훈): **사고 직전 정지율 99~100%를 유지하면서 헛정지를 줄인다.** VLM 확장은 채우 담당이라 여기서 다루지 않는다.

## 지표
- **정지율:** 사고 영상마다 접촉 직전 0.5초(약 15프레임) 동안 정지가 켜져 있었는가. 사고 수 중 몇 건. 라벨은 영상마다 "닿은 순간" 하나(세훈)
- **헛정지:** 사고가 없는 구간(평소 작업 영상, 사고 영상의 정상 구간)에서 정지가 켜진 횟수, 1분당. 1초 안에 다시 켜지면 한 번
- 실험 19까지는 이 지표가 정해지기 전이라 "사고 잡음(사람 첫 정지 2초 전 ~ 접촉 사이에 정지가 켜짐)"과 "평소 작업 118초 헛정지"로 적었다
