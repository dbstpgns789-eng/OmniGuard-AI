# IC-PBL 팀활동보고서 (최종 프로젝트 3일 차)

## 미팅 개요

| 항목 | 내용 |
|------|------|
| 팀이름 | OmniGuard-AI |
| 일시 | 2026-10-21 ~ 2026-10-22 |
| 참석자 | 윤세훈, 이채우 |
| 문제해결과정 | **① 1차 시험:** 처음 보는 사고 20개 화면에서 원칙 규칙 13개, 규칙 4 10개, 조용한 안 2개 → 개발 데이터에 맞춰 다듬을수록 시험에서 떨어짐(과적합 확인)<br>**② 재출발:** 원칙 규칙에서 다시 시작해, 검증 데이터로 후처리 후보를 골라 "정지 유지" 선택 → 2차 시험 정지율 5/10 → 9/10. 대신 평소 멈춘 시간 54% → 67%<br>**③ 3D 시도:** 단안 깊이로 사람이 롤 앞에 있는지 판정 → 사고 순간에도 몸은 롤 앞이라 오히려 사고를 놓침(검증 8/10 → 5/10) → 카메라 한 대의 한계로 결론, 카메라 2대 삼각측량을 다음 단계로<br>**④ 입력 정리:** 잘못 잡힌 관절이 헛정지를 만드는 것을 확인 → 포즈 품질 필터 추가 → 1분당 헛정지 7.6 → 5.7<br>**⑤ 학습 모델:** 사고 9건으로 학습한 MotionBERT는 과적합(교차 검증 10/10, 시험 6/10) → 병목은 데이터 양 → 약한 라벨로 사고를 27건으로 늘림<br>**⑥ 헛정지 거르기:** 1차가 정지를 건 장면만 VLM이 다시 판정 → Qwen이 롤 앞 작업 헛정지의 절반 이상을 거름 |
| 본 미팅의 주요활동 | 1·2차 시험, 3D·학습 모델·VLM 재검증 실험, 결과 통합, 발표자료·데모 영상·대본 완성 |

## 진행 사항

| 항목 | 내용 |
|------|------|
| 이번 미팅에서 한 일(활동 내용) | **판단기 시험과 개선(세훈)**<br>• 최종 판단기(포즈 품질 필터 + 원칙 규칙 + 정지 유지): 처음 보는 사고 10건 중 8건을 닿기 0.5초 전부터 정지, 1분당 헛정지 5.7번, 평소 멈춘 시간 64%<br>• 학습 모델 비교: 그래디언트 부스팅 7/10, 로지스틱 회귀 8/10, MotionBERT 6/10(사고 9건) → MotionBERT + 약한 라벨 사고 27건 10/10<br>• 공정한 비교를 위해 "위험한계 근처면 무조건 정지" 기준선(10/10, 평소 멈춘 시간 75%)을 함께 측정 → 27건 MotionBERT는 놓치지 않으면서 평소 멈춘 시간을 67%로 줄임<br>• 정상 동작만 학습하는 이상 탐지는 3/10으로 실패(사고 직전 동작이 평소 동작과 비슷함)<br>**VLM 실험(채우)**<br>• Qwen3.8-27B로 374장 판정: 실제 정지 장면의 79%를 잡았지만 장면당 0.87초, 정지가 아닌 장면의 27%도 정지로 판정<br>• 2차 확인: 1차 정지 장면을 safe/stop으로 다시 판정. Qwen은 롤 앞 작업 헛정지 53장면 중 30장면을 걸러 내고 진짜 정지 20장면은 모두 유지. imajev는 더 많이 풀지만 진짜 정지까지 풂<br>**발표 준비(공통)**<br>• 발표자료 25장, 데모 영상 2개(성공 사례 카펫 롤러, 한계 사례), 발표 대본 |
| 이번 미팅에서 한 일(조치 사항) | • 최종 판단기를 "포즈 품질 필터 + 원칙 규칙 + 정지 유지"로 확정<br>• 2차 확인 모델은 진짜 정지를 덜 푸는 Qwen으로 정함<br>• 제품 구조를 "AI 1차 판단 → VLM 2차 확인 → 관제실 알림 → 사후 리포트"로 정리<br>• 성능의 핵심 지표를 정지율이 아니라 "정지율을 지키면서 평소 멈춘 시간을 기준선보다 얼마나 줄이는가"로 정함<br>• 데모 영상의 위험한계가 흔들리는 문제를 찾아, 데모는 이동·회전·확대만 쓰는 보정과 시간 평활로 다시 만듦(판단 결과는 같음) |
| 논의 사항 | • 정지율 10/10은 근처면 무조건 멈춰도 나오므로, 숫자만으로 성능을 말하지 않기로 함<br>• Qwen은 장면당 약 0.9초로 느려, 1차가 정지를 냈을 때만 부르는 2차 구조가 맞음<br>• 카메라 한 대의 2D 겹침은 판단 규칙이나 단안 깊이로 풀리지 않아, 맞물림부 카메라 추가가 필요함<br>• 공개된 회전체 끼임 사고 라벨 영상이 거의 없어(iSafetyBench 하나), 현장 알림을 정답지로 쌓는 구조가 필요함 |
