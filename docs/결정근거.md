# 모델과 판단기를 이렇게 정한 이유 (심사 기준 2·3·6, 2026-10-20)

## 1. 왜 사전학습 모델인가 (기준 2)
- **학습할 데이터가 없다.** GitHub·Kaggle·Hugging Face를 다 찾아봐도 "닿기 직전" 끼임 장면은 빨간 상의 하나뿐이었다(`docs/research/12_open_datasets.md`). 사고는 드물고, 모아도 수십 건이라 분류기를 새로 학습하기 어렵다
- **사전학습 모델로 사람과 관절은 충분히 잡힌다.** 공장 고정 CCTV에서 학습 없이 사람 98/100프레임(실험 01)
- **판단은 사람이 설명할 수 있어야 한다.** 정지 하나가 생산을 멈추므로, "왜 멈췄나"를 규칙으로 말할 수 있는 판단기를 택했다. 규칙은 세훈이 장면을 보고 말한 이유를 옮긴 것이다(실험 09·19)

## 2. 왜 이 모델인가 (기준 2)
| 역할 | 고른 모델 | 시험해 보고 뺀 것 | 근거 |
|---|---|---|---|
| 관절 | RTMPose performance (rtmlib, OpenVINO, CPU) | lightweight·balanced | 야간 작업자를 찾은 프레임 4% → 67%, 닿는 순간 0% → 72%(실험 07 t05). 대신 느리다 |
| 사람 탐지 | rtmlib 내장 YOLOX | RF-DETR | RF-DETR은 CPU에서 1초 이상(실험 07) |
| 사람 윤곽(옷) | YOLO11n-seg | - | 헐렁한 옷이 관절보다 롤 쪽으로 앞서는 것을 잡음(실험 16). 판단기 3개에는 넣지 않음 |
| 손 | 쓰지 않음 | MediaPipe Hands | CCTV에서 손이 너무 작아 하나도 못 찾음(실험 07) |
| 깊이 | 쓰지 않음 | Depth Anything V2, 3D 포즈 | 2D 겹침을 못 풀었고 CPU 1초/장(실험 07·08·10) |
| 속도 | OpenVINO + 탐지 5프레임마다 | onnxruntime 매 프레임 | 176ms → 17ms(실험 07, lightweight 기준). performance 모드 속도는 아직 같은 방식으로 재지 않았다 |

## 3. 판단기는 왜 이 모양인가 (기준 3)
판단기는 "정상 → 주의 → 감속 → 정지" 상태 기계다. 입력은 관절과 위험한계 사이 거리(몸통 길이 단위, 안쪽 음수)와 걷는 방향·속도다.

| 결정 | 근거 |
|---|---|
| 거리를 픽셀이 아니라 **몸통 길이**로 잰다 | 카메라마다 사람 크기가 다르다. 몸통 길이로 나누면 같은 값을 여러 영상에 쓸 수 있다 |
| 정지는 **경계에 닿기 전·닿는 순간**, 감속·주의는 그 바깥 | 정답(세훈 판단표)이 "사고를 막으려면 지금 무엇을 해야 하나"라서, 닿은 뒤가 아니라 닿기 전에 단계가 올라가야 한다(실험 07 재채점) |
| 걷기·지나감 인식 | 설비 옆을 지나가는 사람에게 멈추지 않으려고(실험 09) |
| 정지 유지 1초 | 336개 조합 중 좋은 조합에 모두 들어 있었다. 짧으면 깜빡이며 다시 켜진다(실험 18) |
| 위험한계 = 롤 양 끝 원판 | 손·발·머리·옷 어디든 들어가면 위험한 영역. 세훈이 영상마다 그린다 |

## 4. 판단기 3단계: 헛정지를 줄여 온 과정 (기준 3·4)
| 단계 | 판단기 | 무엇을 바꿨나 | 왜 | 사고 잡음 | 평소 헛정지 |
|---|---|---|---|---|---|
| 0 | J09 | 빨간 상의 한 영상에 경계값을 맞춤 | 처음 시도 | 2/5 | 0.5/분 |
| 1 | **J13 원칙** | 어느 영상에도 맞추지 않고 "경계에 닿으면 정지" | 한 영상에 맞춘 값은 다른 영상에서 안 켜졌다(실험 10·12) | 4/4 | 3.6/분 |
| 2 | **RULE4 규칙 4** | 모든 관절에서 출발, 세훈이 헛정지 장면마다 "왜 안전한가"를 말한 것을 규칙으로 | 헛정지 9번 모두 상체였고, 발이 설비 앞선 바깥이면 세훈은 안전으로 봤다(실험 19) | 4/4 | 0.5/분 |
| 3 | **QUIET 조용한 안** | 손이 안쪽 0.7까지 들어와야 정지 | 336개 조합 중 헛정지 0회인 조합(실험 18) | 3/4 | 0/분 |

- J13 → 규칙 4: 사고는 그대로 다 잡으면서 헛정지가 7분의 1로 줄었다
- 규칙 4 → 조용한 안: 헛정지가 0이 되지만 사고 하나를 놓친다. 정지율 99~100%가 목표라 대표는 규칙 4를 권한다(세훈 결정 대기)
- 세 판단기는 `experiments/20_frozen/judges.py`에 시험 전에 고정했다

## 5. 지표 (기준 6)
- **정지율:** 사고 영상마다 닿기 직전 0.5초 동안 정지가 켜져 있었나. 사고가 나면 한 번이 치명적이라 놓침을 가장 먼저 본다
- **1분당 헛정지:** 사고가 없는 구간에서 정지가 켜진 횟수. 1초 안에 다시 켜지면 한 번. 현장에서는 헛정지가 잦으면 사람이 장치를 끈다(`docs/research/04_nuisance_trip.md`)
- **정답:** 세훈 라벨. 채우가 따로 라벨하면 두 사람 일치도도 같이 본다(실험 15)
- **개발용과 시험용을 섞지 않는다:** 판단기를 만들 때 본 영상과 시험 영상을 나눴다(`experiments/20_frozen/README.md`)
