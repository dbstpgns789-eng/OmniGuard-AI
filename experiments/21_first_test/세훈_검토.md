# 세훈 검토: 맞춤용 9건(화면 10개)에서 판단기가 틀린 장면 (2026-10-21)

검토 자료: `OmniGuard-data/세훈_작업/맞춤용_검토/` (0.2초 사진 + 엑셀). 시험용 10건은 열지 않았다.
세훈에게 "이 영상에서만 통하는 이유인지, 어느 공장에서나 통하는 이유인지"를 구분해 달라고 했다.

| 영상 | 세훈 판단 (원문 요지) | 어느 공장에서나? |
|---|---|---|
| A09 / A10 | 포즈가 놓쳤다. 관절 점이 안 보이고 사람의 뒷모습이 보인다. 옷이 낄 수 있는 아주 가까운 상황이라 위험하다. **segmentation을 적용하면 해결되나?** | 예 |
| A09 / A10 | 안전한 이유: 발이 위험한계에 걸쳐 보이지만 작업자는 공간상으로 걸어오는 중이다. 관절이 위험한계와 겹친다고 끼인 것은 아니다 | 예 |
| B01 | **J13이 더 정확한 듯하다.** 설비에 손을 대기 전에 정지해야 한다. 내가 오판한 듯하다. 점점 J13이 잘 맞춘다는 느낌이 든다 | - |
| B02 | 같은 문제다. 위험한계는 2D이고 사람은 그 공간 안에서 움직여 겹쳐 보인다. 끼인 게 아니다. 예민하게 보면 정지가 맞을 수도 있다. 사람의 정지와 몇 프레임 차이라 성공으로 볼 수도 있다 | 예 |
| D01, D02, D03 | 2D 문제가 가장 잘 보인다. 화면에서 회전축이 뒤편, 사람이 앞쪽에 있어 위험한계에 관절이 걸쳐 끼인 듯 보인다 | 예 |
| D06 | 위와 같은 2D 문제. 그리고 사람을 중간중간 계속 놓친다(쭈그려 앉아서인가) | 예 |
| D08 | (적지 않음) | - |
| D11 | J13은 2D 문제를 정확히 보여 주고, **여기서는 규칙 4가 맞다** | - |

## 정리
1. **틀린 이유는 두 가지로 모인다.** (가) 사고 직전에 포즈가 사람을 놓친다(뒷모습, 쭈그려 앉음, 몸을 숙임). (나) 롤이 사람 뒤에 있는데 화면에서 관절이 위험한계와 겹친다(2D 겹침). 둘 다 어느 공장에서나 생긴다
2. **(가)는 사람 윤곽(segmentation)으로 보완할 수 있다.** 관절이 안 보여도 사람 모양은 남는다(실험 16의 YOLO11n-seg). 세훈 제안
3. **(나)는 규칙으로 풀기 어렵다.** 규칙 4가 맞는 영상(D11)도, 틀리는 영상(D02, D06, D08, D11 외)도 있다. 화면만으로는 "앞에 서 있음"과 "들어가는 중"을 구별할 수 없다 → 3D(세훈), VLM(채우)
4. **정답도 완벽하지 않다.** B01에서 세훈은 "J13이 더 정확하다, 내가 오판했다"고 봤다. 판단기가 사람보다 일찍 멈춘 것 중 일부는 틀린 것이 아니라 예방 시점에 더 가깝다
