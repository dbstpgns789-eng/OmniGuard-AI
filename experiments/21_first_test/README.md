# 21. 1차 시험: 고정한 판단기 3개를 처음 보는 사고 영상 20개에 한 번 (2026-10-21)

판단기는 `20_frozen/judges.py`(커밋 1fc9d9f) 그대로 쓴다. 이 문서는 결과를 보기 전에 커밋한다. 결과를 본 뒤 아래 기준을 바꾸지 않는다.

## 데이터
- 영상: `OmniGuard-data/세훈_작업/판단표_사고19/` 20개 (사고 19건, A09·A10은 같은 사고의 다른 화면). 구간은 판단표와 같다
- 정답: 세훈 판단표(정상·주의·정지 3단계, 닿음 Y). 해석 규칙은 같은 폴더 `제외구간.json`(편집 구간 제외, 앞 빈칸은 정상, A10 칸 보정)
- 위험한계·바닥 앞선: 세훈이 그림. 롤마다 원판을 묶어 위험한계 하나(볼록 껍질). 롤이 하나면 실험 12처럼 위험한계 하나, 둘 이상이면 실험 11처럼 설비별로 따로. 바닥선(걷는 방향)은 첫 번째 앞선을 쓴다
- 맞춤용 9개·시험용 10개: `20_frozen/split.json`. 1차 시험은 20개 모두 채점하고, 맞춤용 9개의 틀린 장면만 다음 단계에서 연다

## 전처리 (`prepare.py`)
- 포즈: RTMPose performance(rtmlib, OpenVINO, CPU), 매 프레임 탐지 (개발 때와 같음). 프레임마다 처리 시간(ms)도 기록
- **화면 보정 켬:** 위험한계를 그린 화면을 기준으로, 매 프레임 ORB 특징점 + RANSAC 호모그래피로 카메라 움직임을 구해 위험한계를 따라 옮긴다(실험 10과 같은 방식). 보정을 끈 결과(H=단위행렬)도 같이 저장해 두고, 비교는 나중에 따로 한다

## 지표 (결과 보기 전에 고정)
- **정지율:** 영상마다 닿음 시각 tc(판단표 첫 Y). 판단기 정지가 **tc−0.5초에 켜져 있고 tc까지 계속 켜져 있으면** 성공. 20개 중 몇 개
- **1분당 헛정지:** 세훈이 "정상"이라 적은 구간(제외 구간 빼고)에서 판단기 정지가 켜진 횟수. 1초 안에 다시 켜지면 한 번. 정상 구간 전체 길이(분)로 나눈다
- **첫 정지 시각 차이:** 판단기 첫 정지 − 세훈 첫 정지(초). 음수면 세훈보다 빠름
- **단계 일치:** 판단기 감속은 주의로 합쳐 3단계로 비교, 프레임 정확도와 macro F1 (보조)
- 보고: 20개 전체, 시험용 10개, 맞춤용 9개(A09/A10 포함 10개 화면)를 따로
