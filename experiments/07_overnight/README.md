# 07. 밤샘 실험 묶음 (2026-10-16 01:25 시작)

모든 판단 기준은 **실행 전에** 코드에 적었다. 결과를 본 뒤 기준을 바꾸면 그 사실을 따로 적는다.

## 실행 구조

- `runner.py`: 작업을 순서대로 별도 프로세스로 실행. 끝난 작업(`out/<작업>/DONE`)은 건너뛰고, 작업마다 최대 3번 시도. 실행 중 PC 절전 방지
- `supervisor.ps1`: 실행기가 죽으면 60초 뒤 다시 실행. `ALL_DONE`이 생기면 멈춤
- 작업 스케줄러 `OmniGuard_overnight`: 재부팅 후 로그인하면 감독 스크립트를 다시 띄움. 끝나면 `Unregister-ScheduledTask OmniGuard_overnight`로 지운다
- 상태: `status.json`, 작업별 로그: `logs/`, 결과: `out/<작업>/result.json`
- Colab T4 작업 2개는 Aside가 실행하고 결과를 `OmniGuard-data/colab_results/`에 저장
