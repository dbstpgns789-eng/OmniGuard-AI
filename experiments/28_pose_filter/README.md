# 28. 포즈 품질 필터: 가짜 사람 검출과 튀는 관절 걸러내기 (전처리, 2026-10-21)

결과를 보기 전에 커밋한다.

## 왜
A04 데모에서 화면 왼쪽 기계를 사람으로 잡고, 그 관절을 화면 반대편 롤 끝까지 이어 붙인 프레임이 있었다. 이런 가짜 검출의 관절이 위험한계에 닿으면 정지가 켜지고, 정지 유지(C1)가 그것을 늘린다. A04는 사람이 2명 이상 잡힌 프레임이 46%였지만 실제 작업자는 대부분 1명이다.

## 필터 (모든 데이터에 같게, 기준값은 실행 전 고정)
1. **뼈 길이:** 몸통 길이(common.torso_len)를 구할 수 있는 사람에서, 팔·다리 한 마디(어깨-팔꿈치, 팔꿈치-손목, 엉덩이-무릎, 무릎-발목)가 몸통 길이의 1.5배보다 길면 바깥쪽 관절(팔꿈치·손목·무릎·발목)을 버린다(신뢰도 0)
2. **보이는 관절 수:** 신뢰도 0.3 이상 관절이 6개 미만이면 사람으로 보지 않는다
3. **평균 신뢰도:** 보이는 관절의 평균 신뢰도가 0.4 미만이면 사람으로 보지 않는다

판단기(`20_frozen/judges.py`)와 정지 유지(실험 22)는 그대로다. 입력 포즈만 바뀐다.

## 확인
- 개발 데이터(사고 4건, 프레스 평소 작업 14개): J13이 크게 나빠지지 않는가 (필터 전 사고 4/4, 헛정지 7회)
- 시험 10건(+ 검증 10개 화면): J13, C1의 정지율·1분당 헛정지·평소 정지 시간. 필터 전: 시험 J13 5/10·6.7/분·54%, C1 9/10·7.6/분·67%
