# 23. 단안 깊이로 "사람이 롤보다 앞에 서 있나" 가리기 (2026-10-21)

결과를 보기 전에 커밋한다. 조사: `docs/research/12_depth_models.md`

## 질문
2D 헛정지의 주원인은 "롤은 뒤에 있고 사람은 앞에 서 있는데 화면에서 겹쳐 보이는 것"이다(세훈 검토 D01~D06). 이것은 손-롤 2cm가 아니라 **수십 cm 단위의 앞뒤 판정**이다. 단안 깊이로 "사람이 롤보다 분명히 앞"을 가려 정지를 감속으로 내리면, 정지율을 지키면서 평소에 멈춰 있는 시간을 줄일 수 있는가?

## 실험 07 V4와 다른 점
V4(효과 없음)는 손끝 한 점의 깊이를 봤고, 영상 2개, Claude가 정한 정답이었다. 이번에는 사람 윤곽 전체와 롤 표면을 비교하고, 사고 20개 화면, 세훈 판단표로 잰다.

## 방법 (실행 전 고정)
- 깊이 모델: Depth Anything V2 Small(`depth-anything/Depth-Anything-V2-Small-hf`, Apache-2.0, 상대 깊이 = 가까울수록 큰 값). 설계안의 Video Depth Anything은 저장소를 직접 받아야 하고 연속 프레임용이라 바꿨다
- 프레임: 판단표와 같은 0.2초 간격만 (판단기 프레임에는 가장 가까운 0.2초 값을 쓴다)
- 사람: 실험 22의 사람 윤곽(YOLO11n-seg) 중 위험한계와 가장 많이 겹치는 것. 겹치는 사람이 없으면 판정하지 않음
- 롤: 위험한계 안에서 사람 윤곽이 아닌 픽셀
- **"앞에 서 있음"** = 사람 윤곽 깊이 중앙값이 롤 픽셀 깊이의 90번째 백분위보다 큼 (사람이 롤 표면의 90%보다 카메라에 가까움). 순서만 쓰므로 상대 깊이의 축척과 무관하다. 경계값을 고르지 않는다
- 흔들림: 최근 1초(0.2초 간격 5개) 중 3개 이상이 "앞"일 때만 "앞"
- 판단기: C1(실험 22, 정지 유지)에서 정지인데 "앞에 서 있음"이면 감속으로 내림 = **D1**. 비교로 J13에도 같은 처리 = D0
- 화면 보정 켬, 지표는 실험 21·22와 같음 + 정상 구간에서 정지가 켜진 시간 비율

## 절차와 성공 기준
1. 맞춤용 10개 화면에서 D1과 C1 비교 (고를 후보는 하나뿐이라 확인용)
2. 시험용 10건에 D1 한 번
- 성공: 시험용 정지율 9/10 유지, 정상 구간 정지 시간 67%보다 줄어듦
- CPU 처리 시간(ms/장)도 기록
