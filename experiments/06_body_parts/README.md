# 06. 판단에 쓰는 관절: 손목 2개 vs 관절 17개 전부

## 질문

관절 전부를 판단에 넣으면 손목만 볼 때보다 오정지가 얼마나 늘고, 접촉 순간을 더 잘 잡는가.

## 조건 (실행 전에 정함)

- 바꾸는 변수 하나: 판단에 쓰는 관절 (손목 9·10번 / 17개 전부)
- 고정: 실험 05와 같은 영상 2개, 같은 Tc, 같은 회전체 다각형과 화면 이동 보정, 같은 포즈 결과(한 번 추정해 `*_pose.npz`로 저장), 화면상 겹침 규칙(V1), 정지 연속 확인 3프레임
- 예상(세훈): 관절 전부를 보면 서 있기만 해도 몸이 회전체와 겹쳐 오정지가 크게 는다

## 결과 (`result.json`)

| 영상 | 관절 | 접근 전 오정지 비율 | 접촉 순간(Tc±0.5초) 정지 비율 |
|---|---|---|---|
| 야간 종이 롤 (rec_001918) | 손목 | 0.75 | 0.00 |
| 야간 종이 롤 (rec_001918) | 전부 | **0.99** | 0.00 |
| 빨간 상의 (rec_002103) | 손목 | 0.10 | 0.61 |
| 빨간 상의 (rec_002103) | 전부 | **0.50** | **1.00** |

- 손목 결과는 실험 05의 V1과 같다. 같은 포즈 결과를 다시 써서 재현됐다는 확인이다.
- 관절 전부의 선행 시간은 두 영상 모두 3.0초로 나왔는데, 이것은 측정 창(Tc−3초) 시작부터 이미 정지 중이었다는 뜻이라 의미가 없다.

## 해석

1. 예상대로 관절 전부를 보면 오정지가 크게 늘었다(0.10 → 0.50, 0.75 → 0.99). 평면 화면에서 몸 전체가 회전체와 겹치기 때문이다.
2. 대신 빨간 상의 영상에서는 접촉 순간을 빠짐없이 잡았다(0.61 → 1.00). 손목이 가려져도 다른 관절이 겹침을 잡아 준다.
3. 야간 영상은 어느 쪽이든 접촉 순간 0이다. 작업자 자체를 놓쳤으므로 관절 선택으로는 해결되지 않는다.
4. 결론: "어느 관절을 보느냐"만으로는 오정지와 놓침을 동시에 줄일 수 없다. 겹침이 아닌 다른 신호(손의 움직임 방향, 카메라 시점)가 필요하다. 사례 2건이므로 러닝머신 영상에서 다시 확인한다.
