# 24. 시간 모델: 관절 시계열에서 "정지가 필요한가"를 배우기 (소프트웨어 2.0 첫걸음, 2026-10-21)

결과를 보기 전에 커밋한다.

## 질문
사람이 짠 규칙 대신, 관절의 시간 흐름(최근 1초)을 입력으로 "지금 정지가 필요한가"를 데이터에서 배운 모델이, 처음 보는 사고에서 규칙 기준선보다 나은가?

## 데이터 (실험 20의 분할 그대로)
- 학습: 맞춤용 사고 9건(화면 10개, 세훈 판단표) + 프레스 평소 작업 14개(모두 정상, 실험 11). 전처리는 실험 21과 같음(화면 보정, 편집 구간 제외)
- 시험: 시험용 사고 10건. **한 번만** 채점
- 정답: 세훈 판단표의 "정지" 여부(두 단계: 정지 / 아님)

## 입력과 모델
- 프레임마다 관절에서 뽑은 값 9개: 손-위험한계 거리, 몸(어깨·팔꿈치)-위험한계 거리, 17개 관절 중 가장 가까운 거리, 발 이동 속도, 설비와 나란한 정도, 설비 쪽으로 다가오는 속도, 걷는 리듬, 몸이 향한 방향, 관절을 놓쳤는지 (거리는 몸통 길이 단위, 실험 21과 같은 계산)
- **시간 창:** 최근 1초를 0.2초 간격 6시점으로 쌓아(9 × 6 = 54개 입력) 한 번에 넣는다. 여러 프레임을 모델 입력으로 넣는 방식
- 모델: 그래디언트 부스팅 트리(scikit-learn HistGradientBoosting), 정지 프레임이 적어 클래스 가중치 균형. 학습 데이터로 하이퍼파라미터를 고르지 않고 기본값을 쓴다
- 판정: 정지 확률 0.5 이상이면 정지. 비교를 위해 실험 22의 정지 유지 후처리를 얹은 것도 같이 잰다
- 학습 데이터 안에서 영상 하나씩 빼고 학습·평가(교차 검증)도 함께 보고한다

## 비교 대상 (같은 시험 10건, 실험 21·22)
- J13 원칙: 정지율 5/10, 평소 정지 시간 54%
- C1 정지 유지: 9/10, 67%

## 지표
정지율(닿기 0.5초 전부터 닿을 때까지 정지 유지), 헛정지 횟수(1분당), 평소 정지 시간 비율

## 결과 (`result.json`)
| 모델 | 시험 정지율 | 헛정지/분 | 평소 정지 시간 |
|---|---|---|---|
| 시간 모델 (확률 0.5 그대로) | 1/10 | 9.6 | 21% |
| **시간 모델 + 정지 유지** | **7/10** | **4.8** | **62%** |
| (비교) J13 원칙 | 5/10 | 6.7 | 54% |
| (비교) C1 = J13 + 정지 유지 | 9/10 | 7.6 | 67% |

- 교차 검증(맞춤용 안에서 사고 하나씩 빼고 학습): 그대로 0/10, 정지 유지 6/10
- 모델 출력 그대로는 정지가 깜빡여 "닿기 0.5초 전부터 계속 정지"를 거의 못 채웠다. 정지 유지를 얹어야 쓸 수 있었다
- 정지 유지를 얹은 시간 모델은 규칙(C1)보다 정지율은 낮고(7/10 vs 9/10), 헛정지는 적었다(4.8 vs 7.6/분, 평소 정지 시간 62% vs 67%). D12는 평소에 한 번도 안 멈추고 사고 직전에만 멈췄지만, A04는 놓쳤다
- 학습 데이터가 사고 9건뿐이고, 입력이 규칙과 같은 2D 관절 값이라 같은 벽에 부딪혔다. 학습 모델로 바꾸는 것만으로는 2D 한계를 넘지 못한다 → 더 많은 데이터, 영상 자체를 보는 모델(VLM), 3D
