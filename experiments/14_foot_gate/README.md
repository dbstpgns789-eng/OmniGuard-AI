# 14. 겹침이 진짜인지 확인하기: 발 위치 → 안전 증거 → 머무름 (설계, 실행 전)

상태: **설계 검토 중** (세훈 승인 후 실행)

## 질문

화면에서 손이 위험한계와 겹쳤을 때, 그 겹침이 진짜인지 확인하는 정보를 하나씩 더하면, 사람이 멈추라고 한 순간은 그대로 잡으면서 헛정지를 줄일 수 있는가?

## 근거 (`docs/조사_헛정지줄이기.md`)

- 회전 롤러 현장에서 손이 아니라 **발**의 위치로 2D 겹침을 걸러내 오경보 34~57% 감소, 민감도 유지 (Depth-Assisted Industrial Safety Monitoring, 2025)
- 위치에 **이동 방향**을 더해 오경보 79% 감소 (hoisting intrusion, 2026)
- 여러 프레임 확인으로 오경보율 2.03% (construction temporal analysis, 2024)
- 상용(SICK, Intenseye, Altendorf): 애매하면 **감속**, 정지는 증거가 겹칠 때
- 경계값은 영상에 맞추지 않고 **ISO 13855**에서 계산: 팔이 닿는 거리 C = 0.85m, 보행 속도 K = 1.6m/s

## 왜 발인가

공중의 손은 화면에서 앞뒤를 알 수 없다. 발은 항상 바닥(높이 0)에 있으므로, 세훈이 그린 바닥 평행선으로 바닥 평면을 잡으면 평면 화면에서도 실제 바닥 위치로 바꿀 수 있다. 실험 09-2(3D 보정)는 공중의 손 높이를 추정해야 해서 실패했지만, 발은 그 추정이 필요 없다.

## 바닥 좌표 만드는 법 (실험 09-2 코드 재사용)

1. 세훈이 그린 바닥 선 4개 → 소실점 2개 → 초점 거리와 카메라 기울기
2. 축척: **사람 키 = 1.7m**로 둔다. 똑바로 선 프레임에서 발목~코 높이로 카메라 높이를 정한다
3. 발목 중점 → 바닥 좌표(m)
4. 위험 설비의 바닥 앞선(새로 그림, 아래 "세훈이 할 일") → 발에서 그 선까지 거리 d_foot(m)

키를 가정하므로 거리에는 약 ±10% 오차가 있다. 경계값에 여유를 둔다.

## 판단 규칙 (경계값은 모두 실행 전에 표준에서 정함, 어느 영상에도 맞추지 않음)

공통: 손 겹침 = 손목(안 보이면 팔꿈치로 추정)이 세훈이 그린 위험한계(원통) 안. 실험 13과 같다.

| 단계 | 쌓는 순서 | 규칙 |
|---|---|---|
| A0 기준선 | 비교용 | 손 겹침이면 정지 (실험 08 V1) |
| A1 참고 | 비교용 | 실험 09 판단기(깊은 경계값), 실험 13 판단기(원칙 경계값) |
| **S2 발 위치** | 아이디어 2 | 정지 = 손 겹침 AND 발이 도달 거리 안(d_foot ≤ 0.85m + 여유 0.15m = **1.0m**). 손 겹침이지만 발이 밖 → **감속**. 발이 안 보임(가려짐) → **감속**. 주의 = d_foot ≤ 1.6m/s × 0.5초 + 0.85m ≈ **1.65m** |
| **S2+1 안전 증거** | 아이디어 1 | S2에서, 바닥 좌표로 잰 발 이동이 설비와 나란하고(지나감) 설비 쪽으로 다가오지 않으면 정지 → 감속으로 내림. 상체가 꼿꼿하고(어깨-골반 기울기 < 15°) 양 손목이 어깨보다 낮으면 같은 처리 |
| **S2+1+4 머무름** | 아이디어 4 | 정지는 최근 3스텝(0.2초 간격) 중 2스텝 충족 시. 해제는 1초 유지 + d_foot > 1.3m(도달 거리 + 0.3m) |

- 0.5초(T)는 판단 지연 + 기계 정지 시간을 모르는 인터넷 영상이라 가정한 값이다. 러닝머신에서는 실제로 잰 정지 시간을 넣는다.
- 걷기 판단은 실험 09처럼 몸통 단위·화면 좌표가 아니라 **바닥 좌표(m/s)**로 다시 계산한다. 걷는 속도 기준 0.5m/s, "나란함"은 이동 방향과 설비 방향의 각도 30° 이내.

## 데이터와 정답 (모두 세훈 판단표, 새로 판단할 것 없음)

| 묶음 | 영상 | 정답 |
|---|---|---|
| 개발 | 빨간 상의 (09) | 09 판단표 |
| 시험 | 넓은 화면 4개 (10), 사고 5건 (12) | 10·12 판단표 |
| 헛정지 | 프레스 평소 작업 14개 (11) | 전부 정상 |

경계값을 맞추지 않으므로 교차검증은 필요 없다. 대신 결과를 본 뒤 경계값을 바꾸면 그 사실을 따로 적고, 바꾼 값은 "개발" 영상에서만 정한다.

## 측정 (조사의 평가 방식을 따름)

1. **사람 정지 구간을 잡은 비율** (재현율). 감속으로 덮은 비율도 따로
2. **첫 정지 시각 - 사람 첫 정지 시각**
3. **평소 작업 1분당 헛정지 횟수** (정지가 켜진 횟수)
4. 사람이 정지가 아니라고 본 구간의 정지 비율
5. 발이 안 보여서 판단을 감속으로 내린 프레임 비율 (발 방법의 적용 범위)

## 미리 정한 성공 기준

- 사고 5건 중 사람이 정지로 본 구간을 실험 13만큼(4건) 잡는다
- 평소 작업 헛정지가 1분에 **1번 이하** (실험 13은 약 5번, V1은 3.6번)
- 둘 다 못 넘으면, 어느 아이디어에서 무엇이 막혔는지 장면을 열어 기록한다

## 예상

- S2는 "설비 앞을 멀리 지나가는" 헛정지(실험 11의 언코일러 장면)를 줄인다
- S2는 봉투기처럼 "원래 설비 바로 앞에서 일하는" 헛정지는 못 줄인다 → S2+1이 필요
- 발이 설비에 가려지는 장면(야간 영상에서 몸을 숙일 때)에서는 감속으로 내려가 정지가 늦어질 수 있다
- 택배 컨베이어(사람이 벨트 위에 서 있음)는 발이 처음부터 설비 위라 S2로는 잡히지만, 위험한계 정의 문제는 남는다

## 세훈이 할 일 (실행 전)

영상마다 **위험 설비의 바닥 앞선**을 클릭 2번으로 긋는다(위험한 롤 바로 아래, 사람이 서는 쪽 바닥선). 빨간 상의, 넓은 화면, 프레스(피더·언코일러 2개), 사고 5건 = 그림 8장, 약 10분.
