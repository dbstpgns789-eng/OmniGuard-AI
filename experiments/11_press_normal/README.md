# 11. 평소 작업 중에 괜히 멈추지 않는가 (헛정지 시험)

## 질문

빨간 상의 영상(09)에 맞춘 판단기가, 처음 보는 공장·처음 보는 롤러 설비 근처의 평소 작업과 통행 장면에서 헛정지를 얼마나 내는가.

## 조건

- 데이터: Safe_and_Unsafe_Behaviours 가까운 시점(A) 영상 60개 중, 사람이 코일 피더·언코일러 근처에 온 14개(`../02_zone_rule/scan_feeder.py`). 사고 장면은 없다
- 위험한계: 사용자가 그린 설비 2대(피더 롤러 입구, 언코일러)를 따로 본다(`zone_objects.json`). 바닥 선 `floor_user.json`
- 정답: 사용자가 1초 단위로 판단한 124초 모두 "정상"(메모: "화면상 설비 앞으로 보이지만 실제는 그 앞 공간을 지나감" 등)
- 판단기: 09 t13 경계값을 바꾸지 않고 그대로. 포즈는 performance(OpenVINO). 비교로 "손목이 윤곽 안이면 정지"(V1, 3프레임 확인)

## 결과 (`result.json`)

| | 판단기 | V1 |
|---|---|---|
| 헛정지 횟수 (118초) | **1** | 7 |
| 1분당 | **0.5** | 3.6 |
| 프레임 판단 | 정상 97.6%, 주의 1.7%, 감속 0.2%, 정지 0.4% | |

유일한 헛정지는 `2_tr86` 3.7초. 사용자 메모 "언코일러 앞을 좌측에서 지나가는 모습". 화면에서 몸이 언코일러와 겹쳐 보였고, 사람이 작고 일부 가려져 "지나감"으로 인식하지 못했다(2D 겹침).

## 해석

한 영상에서 사람 판단 이유를 옮겨 만든 규칙(걷기 인식, 측정 품질 확인, 다가오는 흐름)이 처음 보는 공장과 설비에서도 헛정지를 단순 규칙의 7분의 1로 줄였다. 데모: `OmniGuard-data/exp11/demo_press_normal.mp4`
