# 17. 손이 롤 "안으로" 들어가는 단서: 가림과 팔 단축 (설계, 실행 전)

상태: 실행 완료 (2026-10-20). 결과는 아래

## 질문
원칙 경계값 판단기(J13)는 사고를 많이 잡지만 평소 작업에서 1분에 5번 멈춘다. 정지를 내릴 때 **"손이 실제로 롤 안쪽으로 들어갔다"는 증거**를 요구하면, 사고는 그대로 잡으면서 헛정지를 줄일 수 있는가?

## 왜
- 실험 14: "안전 증거(꼿꼿한 자세)가 있으면 정지 해제"는 위험한 순간까지 지웠다. 조사 결론: 해제를 안전 증거로 걸지 말고, **위험 증거가 있을 때만 정지를 허락**하는 쪽으로 (`docs/research/03_foreshortening.md`)
- 팔 단축으로 "손이 설비 안으로"를 판단한 공장 안전 연구는 없다

## 단서 2개 (포즈 파일만으로 계산, 새 모델 없음)
1. **가림:** 최근 1초 안에 위험한계 안에 보이던 손목이, 지금은 신뢰도가 떨어져 안 보이고 같은 팔의 팔꿈치는 위험한계 근처(감속 거리 안)에 있다 → 손이 롤 뒤로 들어갔다
2. **팔 단축:** 팔뚝(팔꿈치~손목) 화면 길이가 그 영상에서의 평소 길이보다 짧고(비율 r < 0.8), 그 손목이 위험한계 안에 있다 → 팔이 화면 안쪽(롤 쪽)으로 뻗었다
   - 평소 길이 = 그 영상의 모든 사람·프레임에서 팔뚝 길이 ÷ 몸통 길이의 90번째 백분위 (영상마다 한 번)

## 규칙 (경계값은 실행 전에 고정)
| 조건 | 결과 |
|---|---|
| 판단기가 정지이고, 최근 0.4초 안에 단서 1 또는 2가 있음 | 정지 유지 |
| 판단기가 정지인데, 최근 0.4초 안에 단서가 하나도 없음 | **감속으로 내림** |
| 옷 신호의 겹침 정지(실험 16) | 그대로 정지 (손이 아니라 옷이 위험) |
| 그 외 | 판단기 결과 그대로 |

- 얹을 판단기: J13, J13+옷 (실험 16), 비교로 J09, J09+옷도
- 경계값: r < 0.8(조사 제안값), 가림 기억 1.0초, 단서 유지 0.4초

## 데이터와 정답
실험 16과 같다. 사고 5건(정답 A, B 한 칸 올림), 프레스 평소 작업 14개(118초)

## 미리 정한 성공 기준
- **프레스 평소 작업:** J13의 헛정지가 절반 이하로 준다 (10회 → 5회 이하)
- **사고 5건:** 잡은 영상 수가 줄지 않는다 (J13 4/5, J13+옷 4/5)
- **봉투기:** J13+옷의 첫 정지가 크게 늦어지지 않는다 (5.0초 → 5.5초 이내)

## 예상
- 롤 앞에 서서 손을 내리고 일하는 사람은 팔이 짧아 보이지 않고 손도 보이므로, 단서가 없어 정지가 감속으로 내려간다 → 헛정지 감소
- 위험: 카메라가 위에서 내려다보면 아래로 향한 팔도 짧아 보인다(조사 지적). 그러면 평소 작업에서도 단서가 켜져 효과가 줄어든다
- 위험: 슬리터처럼 처음부터 몸이 설비 안에 있는 사고는 손이 보이지 않아도 가림 조건(최근 1초 안에 보였어야 함)이 안 켜질 수 있다

### 왜 안 됐나
- **팔 단축 단서가 평소 작업에서도 켜졌다.** 프레스 헛정지 장면에서 작업자는 피더 위에 손을 올려 일하는데, 위에서 내려다보는 카메라에서는 아래로 뻗은 팔도 짧아 보인다(설계 때 예상한 위험). 그래서 헛정지가 난 바로 그 순간에 단서가 켜져 정지가 유지됐다.
- **J13+옷+단서는 오히려 늘었다(14 → 20회).** 단서가 깜빡이면서 하나의 긴 정지가 "정지 → 감속 → 정지"로 쪼개져, 켜짐 횟수가 늘었다.
- **가림 단서는 평소 작업에서 한 번도 켜지지 않았다(0프레임).** 사고 영상에서는 야간 종이 롤 104프레임, 슬리터 26프레임, 리와인더 4프레임, 컨베이어 3프레임에서 켜졌다. 평소 작업과 사고를 가르는 신호로는 가림 쪽이 훨씬 깨끗하다.

## 인사이트
1. 팔이 짧아 보이는 것은 "롤 안으로 뻗음"과 "설비 위에 손을 얹고 일함"을 구분하지 못했다. 천장 카메라에서는 두 동작 모두 팔이 화면 안쪽을 향하기 때문이다. 2D 깊이 문제가 팔 길이에도 그대로 있었다.
2. 반대로 "보이던 손이 롤 근처에서 사라짐"은 평소 작업에서는 전혀 없고 사고에서만 나타났다. 실험 03부터 문제였던 "위험한 순간에 관절이 사라진다"가 그대로 쓸모 있는 신호가 됐다.
