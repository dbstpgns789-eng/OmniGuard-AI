# 09. 빨간 상의 영상에서 사람 판단(정상/주의/감속/정지)에 모델을 맞추기

## 목표

사용자(세훈)가 0.2초 단위로 표시한 판단(`OmniGuard-data/exp08/frames_for_review/red_crop/판단표.csv`)과 같은 시점에 모델이 주의·감속·정지를 내게 만든다. 이 영상에 맞추는 것(과적합)은 허용했다. 대신 정직한 비교용으로 "앞 절반으로 맞추고 뒤 절반으로 확인"과 "시간 구간 교차검증" 점수도 함께 낸다.

## 바뀐 점: 원통(캡슐) 위험 구역

사용자 그림(파란 축 + 노란 띠)대로, 다각형 대신 **롤의 중심축 선분 + 반지름**으로 회전체를 표현한다. 손목에서 원통 표면까지의 화면 거리를 몸통 길이로 나눈 값으로 단계를 정한다. 화면 이동은 실험 08의 보정 행렬로 따라간다.

## 작업 (`runner.py`, 끊겨도 이어서 실행)

| 작업 | 내용 |
|---|---|
| t1 원통 규칙 | 축 위치·반지름·임계값 3개·평활 창을 무작위 탐색 |
| t2 분류기 | 원통까지 거리, 팔꿈치·코 거리, 숙임, 접근 속도, 최근 1초 최솟값 등으로 랜덤 포레스트·부스팅. 구간 교차검증 + 전체 학습 |
| t3 큰 포즈 모델 | performance 모드(OpenVINO)로 포즈 재추정 |
| t1·t2·t5 (performance) | 큰 포즈 모델로 다시 맞추고 렌더링 |
| t5 렌더 | 원통 구역을 입체처럼 그린 데모 영상, 하단에 사람·규칙·분류기 기록 막대 |
| t6 V5 깊이 | 미터 단위 깊이 모델로 손목-회전체 3D 거리 (실험 08 스크립트) |
| t7 요약 | 결과 모음 |

## 첫 결과 (가벼운 포즈 모델)

사용자 정지 시작: **8.73초, 35.33초**

| 방식 | 단계 일치 (macro F1) | 정지 시작 시각 |
|---|---|---|
| 원통 규칙, 조정 전 | 0.26 | 7.0, 10.2, 12.0, 18.7, 20.0 … (헛정지 다수) |
| 원통 규칙, 전체에 맞춤 | 0.53 | **8.67**, 22.0, 23.4, **36.2**, 이후 깜빡임 |
| 분류기(랜덤 포레스트), 전체에 맞춤 | **0.94** | **8.8**, 24.7, **35.4**, 43.7, 46.1 |
| 분류기, 구간 교차검증(처음 보는 구간) | 0.51 | 8.6, 9.5 … 36.6 … (깜빡임 다수) |

- 전체에 맞춘 분류기는 사람이 표시한 두 정지 시점을 0.1초 이내로 맞힌다. 헛정지는 24.7초 한 번(그리고 사고 뒤 43.7초 이후)뿐이다.
- 처음 보는 구간에서는 0.51로 떨어진다. 이 영상 하나에 맞춘 결과라는 뜻이다.
- 분류기가 가장 많이 쓴 특징: 코와 원통 사이 거리(0.26), 최근 1초 손목 거리 최솟값(0.22). 손목 하나보다 "머리가 롤에 붙었는가"와 "최근에 손이 깊이 들어갔었는가"가 사람 판단과 잘 맞았다.

데모 영상: `OmniGuard-data/exp09/demo_red_lightweight.mp4`
