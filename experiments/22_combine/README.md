# 22. 판단기 섞기: J13 + 정지 유지 + 사람 윤곽 보조 (2026-10-21)

실험 21(1차 시험)과 세훈 검토(`21_first_test/세훈_검토.md`)에서 나온 결론으로 후보 3개를 만든다. 후보와 고르는 규칙은 맞춤용 영상을 채점하기 전에 커밋한다.

## 왜
- 처음 보는 사고에서 정지를 가장 많이 지킨 것은 가장 단순한 J13이었다(13/20). B01에서 세훈도 "J13이 더 정확하다"고 봤다 → 바탕은 J13
- J13이 틀린 이유 중 어느 공장에서나 생기는 것 두 가지: (가) 정지를 켰다가 닿기 직전에 끔(4건), (나) 사고 직전 포즈가 사람을 놓침(A09, D08, 일부 A10·D06·D10). 세훈 제안: 사람 윤곽(segmentation)
- 2D 겹침(롤은 뒤, 사람은 앞)은 규칙으로 풀지 않는다(본 장면에만 맞춰질 위험, 세훈 판단). 결론에 한계로 적는다

## 후보 (모두 J13 위에 얹음, 경계값은 J13 것 그대로)
| 후보 | 규칙 | 근거 |
|---|---|---|
| **C1 정지 유지** | J13이 한 번 정지하면, 사람이 위험한계 근처(손 또는 몸이 J13 감속 거리 0.5 안)에 있거나 포즈를 놓친 동안은 정지를 끄지 않는다. 근처를 벗어난 상태가 1초 이어지면 J13 결과로 돌아간다 | 기계 안전 표준: 안전 정지 뒤에는 위험이 사라지고 사람이 리셋해야 다시 돈다 |
| **C2 윤곽 보조** | 포즈를 놓친 프레임(어떤 사람도 관절 3개 이상이 신뢰도 0.3 이상으로 보이지 않음)에서, 사람 윤곽 면적의 10% 이상이 위험한계 안이면 정지. 0.2초 간격 3스텝 중 2스텝 이상일 때 | 관절이 안 보여도 사람 모양은 남는다. 10%와 3스텝 중 2는 실험 16 값 그대로 |
| **C3** | C1 + C2 | |

- 사람 윤곽: YOLO11n-seg(COCO 사전학습, 학습 없음), 사람만, 신뢰도 0.25 (실험 16과 같음)
- 화면 보정 켬 (실험 21과 같음)

## 고르는 규칙 (맞춤용 10개 화면에서만)
1. 정지율이 가장 높은 후보
2. 같으면 1분당 헛정지가 적은 후보
3. 그래도 같으면 단순한 순서(C1 → C2 → C3)

지표와 채점 코드는 실험 21과 같다(`21_first_test/evaluate.py`의 labels·episodes, 정지율 = 닿기 0.5초 전부터 닿을 때까지 정지 유지).

## 그다음
고른 후보 하나만 시험용 10건에 한 번 돌린다(2차 시험). 비교 대상은 같은 10건의 J13(1차 시험 5/10, 헛정지 6.7/분).

## 맞춤용 10개 화면 결과 (`result_tune.json`)
| 후보 | 정지율 | 헛정지 (정상 0.94분) |
|---|---|---|
| J13 (비교) | 8/10 | 8회 (8.5/분) |
| **C1 정지 유지** | 8/10 | 7회 (7.5/분) |
| C2 윤곽 보조 | 8/10 | 8회 (8.5/분) |
| C3 둘 다 | 8/10 | 7회 (7.5/분) |

- 고르는 규칙대로 **C1** (정지율 같음 → 헛정지 적음 → 단순한 쪽)
- 정지율은 어느 후보도 J13보다 오르지 않았다. 못 잡은 2개(A09, A10)가 그대로다
- **윤곽 보조가 효과 없던 이유(A09·A10 닿기 직전 확인):** 포즈가 사람을 놓친 순간에 **사람 윤곽(YOLO11n-seg)도 사람을 놓쳤다**(윤곽 0개). 같은 순간(몸을 숙임, 뒷모습, 흐림)에 두 모델이 함께 실패한다 → 세훈 질문 "segmentation을 적용하면 해결되나?"의 답은 이 영상들에서는 "아니다"
- A09에서 J13은 닿기 직전 내내 감속(손이 파이프에서 몸통 0.35~0.45)이었고, 닿은 뒤 0.1초에 정지했다. 손이 아니라 옷이 먼저 걸린 사고라 손 거리로는 늦다
