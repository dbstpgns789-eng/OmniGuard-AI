## 1부: 두 사람의 일치도
**활성 구간**: 두 사람 중 누구든 처음 "정상이 아닌" 판단을 한 시각 5초 전부터 채점 구간 끝까지 (정상이 대부분인 구간이 일치도를 부풀리는 것을 막음)

| 지표 | 계산 | 합격선 |
|---|---|---|
| Krippendorff α (서열) | 활성 구간, 5개 영상 합쳐서 + 영상별 | **≥ 0.667 잠정 사용, ≥ 0.800 신뢰** |
| 선형 가중 κ | 같은 구간 | 보고만 |
| 완전 일치율, ±1단계 일치율 | 같은 구간 | 보고만 |
| 정지 시작 차이 | B의 첫 정지 − A의 첫 정지 (초), 영상별 | **중앙값의 절댓값 ≤ 1.0초** |
| 주의 이상 시작 차이 | 같은 방식 | 보고만 |

α < 0.667이면: 어느 한 사람의 판단만 정답으로 쓰지 않는다. 두 사람이 어긋난 장면을 열어 이유를 기록하고, 판단 기준(무엇을 보면 정지인가)을 글로 정리하는 것을 다음 할 일로 둔다.

## 2부: 판단기 채점
**정답 5가지** (모든 지표를 각각 계산): A, B, A∩B(둘 다 정지일 때만 정지), A∪B(한 명이라도 정지면 정지), 접촉 기준(t_c 이후 정지)

**세 구역** (A·B를 합칠 때):
- 둘 다 정지 = **반드시 잡아야 하는 구간**
- 한 명만 정지 = **논쟁 구간** (헛정지로 세지 않음)
- 둘 다 정지가 아님 = **합의 정상 구간** (여기서 정지하면 헛정지)

| 지표 | 계산 | 고정값 |
|---|---|---|
| 사고 잡음 (영상 단위) | 판단기의 첫 정지가 [사람 첫 정지 − 2.0초, t_c] 안이면 잡음. 5개 중 몇 개, Clopper-Pearson 95% 구간 | 허용 창 2.0초 |
| 너무 이른 정지 | 위 창보다 먼저 켜졌다가 창 전에 꺼진 정지는 헛정지로 셈 | |
| 정지 구간 재현율 | 반드시 잡아야 하는 구간 중 판단기가 정지인 프레임 비율 | |
| 리드타임 | t_c − 판단기 첫 정지 (초), 영상별, 최솟값과 중앙값 | |
| 사람 대비 차이 | 사람 첫 정지 − 판단기 첫 정지 (초) | |
| 헛정지 횟수 | 합의 정상 구간에서 정지가 켜진 횟수(1.0초 안에 다시 켜지면 한 번으로), 1분당, Garwood 95% 구간 | 병합 간격 1.0초 |
| 단계 오류 | 정답보다 낮게(과소) / 높게(과잉) 판정한 비율, **치명적 놓침**(정답 정지인데 판단기 주의 이하) 비율, 정답 또는 한 단계 더 조심한 비율 | |

**사람 천장**: B를 판단기처럼 놓고 A 기준으로 같은 지표를 계산한다(반대 방향도). 판단기 점수를 이 값과 나란히 보고한다.

## 결론을 말하는 규칙
- 판단기에 대한 결론("J13이 J09보다 사고를 많이 잡는다" 등)은 **정답 A, B, A∩B 세 가지 모두에서 같은 방향일 때만** 주장한다. 하나라도 뒤집히면 "정답 정의에 따라 달라진다"고 쓴다.
- 모든 수치는 n과 구간을 같이 쓴다. 예: "사고 4/5 (95% 구간 0.28~0.99)", "헛정지 0회 / 2.0분 (95% 상한 1.84회/분)".
- 사고 5건은 성능 주장이 아니라 방법 검증과 실패 분석이다.
