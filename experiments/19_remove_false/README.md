# 19. 정지는 원칙대로 다 잡고, 헛정지를 하나씩 없애기

세훈 방침(2026-10-20): "몸 어디든(손·발·머리·옷) 위험한계에 들어가면 위험"을 원칙으로 두고 출발해, 사고를 다 잡는 상태에서 헛정지를 한 번에 하나씩 없앤다. 각 규칙은 세훈이 헛정지 장면을 보고 적은 이유(`OmniGuard-data/exp19/step0/확인표.csv`)에서 나왔다. 택배 컨베이어 사고는 폐기(위험한계 정의 문제), 사고 영상은 4건.

| 단계 | 바꾼 것 | 코드 | 사고 4건 (세훈/채우) | 평소 작업 헛정지 (118초) |
|---|---|---|---|---|
| 출발점 | 17개 관절 중 하나라도 위험한계에 닿으면 정지, 간격 0.25, 유지 1초 | step0.py | 4/4 / 4/4 | 9회 (4.6/분) |
| 바닥선 끄기 | "지나감" 판단(바닥선 사용) 켬/끔 비교 | step0.py | 같음 | 같음 → 바닥선은 이 판단기에 영향 없음 |
| 규칙 1 | 상체가 겹쳐도 발이 설비 바닥 앞선에서 1m보다 멀면 무시 + 같은 카메라는 높이 한 번만 추정(3.89m) | step1.py | 4/4 / 4/4 | 7회 |
| 규칙 2 | 바닥에서 설비와 나란히 걸어 지나가면 상체 겹침 무시 | step2.py | 4/4 / 4/4 | 6회 |
| 규칙 3 | 발목이 안 보이면 무릎·엉덩이로 발 추정 | step3.py | 4/4 / 4/4 | 6회 (효과 없음) |
| **규칙 4** | 발이 설비 앞선 바깥(사람 쪽)이면 머리·어깨·엉덩이 겹침 무시, 손·팔꿈치는 안쪽 0.7까지 들어와야 정지. 무릎·발목은 항상 정지. 발을 모르면 원칙 그대로 | step4.py | **4/4 / 4/4** | **1회 (0.5/분)** |

- 헛정지 원인은 9번 모두 상체(머리·어깨·팔·손)였고 발·무릎은 0번이었다.
- 세훈 판단: 남은 장면(1_tr38, 1_tr54, 2_te6, 2_tr86)은 모두 안전. 판단기 바닥 계산으로는 발이 언코일러·피더 앞선에서 0.3~0.9m였다(`OmniGuard-data/exp19/foot_check/`). 세훈은 "2D를 보고 공간을 상상해" 안전 구역을 걷는다고 판단 → 규칙 4로 반영.
- 비교: 조용한 안(실험 18 대표)은 사고 3/4, 헛정지 0회. 규칙 4는 4/4, 1회.
- 같은 프레스 영상 14개를 보며 만든 규칙이라 새 영상에서 확인이 필요하다(`docs/videos/종합.md`의 수집 영상).
