# 03. 롤 맞물림부 끼임 사고 직전 캡처에서 구역 규칙 확인

## 질문

범위를 "회전 롤 맞물림부 끼임"으로 정했다(2026-10-15). 02의 손목-구역 규칙이 실제 사고 직전 장면에서 반응하는가.

## 조건

- 사용자 캡처 중 롤 맞물림부 장면 12장(user_01~03·08~09·11~13·17~20). user_10은 설비가 안 보여 제외. 캡처는 재배포 금지라 레포 밖(`accident-refs/`)에 있고, 확인 이미지도 그쪽 `nip_check_sheet.jpg`에 저장
- 정지 화면 한 장씩이라 시간 조건(연속 프레임 확인)은 없다. 사고 장면만 있어서 오경보율은 잴 수 없다
- 구역: 회전 롤 몸체 + 맞물림부를 사람이 격자를 보고 그림(`check_refs.py`의 `ZONES`)
- 포즈: rtmlib `Body` lightweight, CPU. 캡처가 작아서 높이 720px로 키움

## 결과 (`result.json`)

손목 기준 8/12, 관절 아무거나 기준도 8/12. 장면을 직접 보면 의미가 갈린다.

| 구분 | 캡처 | 원인 |
|---|---|---|
| 제대로 잡음 | 08, 11, 12, 13 | 손목이 설비 개구부·롤 아래 안에 있음 |
| 잡았지만 근거 약함 | 17, 18, 19, 20 | 구역을 롤 몸체 전체로 그려서, 롤 앞에 서 있기만 해도 2D 화면에서 겹친다. 지나가는 사람에게도 반응할 구조(02의 깊이 겹침 문제와 같음) |
| 포즈 실패 | 01, 02, 03 | 상체가 설비 안으로 들어가 가려짐 + 흑백·저해상도. 손목 신뢰도 0.14~0.16 |
| 구역을 잘못 그림 | 09 | 사람이 롤 끝면 옆에 있는데 구역에 끝면을 넣지 않음 |

## 알게 된 것

1. 몸이 설비 안으로 들어갈수록 키포인트가 사라진다. 가장 위험한 순간에 포즈가 실패하므로, 사람 박스와 구역의 겹침을 보조 신호로 둬야 한다.
2. 큰 롤은 2D 화면에서 사람과 겹치기 쉽다. 시연 카메라는 롤 축 방향 옆이나 위에서 맞물림부를 보게 두고, 구역은 롤 전체가 아니라 맞물림선 주변 띠로 좁힌다.
3. 사고 장면만으로는 규칙을 평가할 수 없다. 같은 카메라로 찍은 정상 작업·통행 장면이 함께 있어야 한다 → 연기 촬영.
