# 26. 데이터를 늘려 MotionBERT 다시: A 정상 동작만으로 배우기(이상 탐지), B 약한 라벨로 사고 늘리기 (2026-10-21)

결과를 보기 전에 커밋한다. 실험 25에서 MotionBERT는 검증 10/10, 시험 6/10이었다. 병목이 사고 9건이라는 데이터 양이어서, 데이터를 늘리는 두 방법을 시험한다.

## 공통
- 동작 표현: MotionBERT(NTU60 행동 인식 미세조정 인코더, 고정), 0.2초 간격마다 최근 1초 → 512차원 (실험 25와 같음)
- **입력 프레임 수를 맞춤:** 새 영상은 계산량 때문에 초당 10장으로 포즈를 계산한다. 시험·검증 영상도 기존 포즈에서 초당 10장만 골라 똑같은 조건으로 동작 표현을 다시 뽑는다
- 사람 고르기: 위험한계가 있는 영상(검증·시험·프레스)은 위험한계에 가장 가까운 사람, 위험한계가 없는 영상(약한 라벨 사고, Safe and Unsafe)은 화면에서 가장 큰 사람
- 판정 뒤: 사람이 위험한계 근처(몸통 0.5배 안, 17개 관절 중 가장 가까운 것)일 때만 정지(위험한계 정보는 시험 때만 씀) + 정지 유지 후처리(실험 22)
- 시험: 시험용 10건 한 번. 지표: 정지율, 1분당 헛정지, 평소 정지 시간

## A. 정상 동작만으로 배우기 (이상 탐지)
- 정상 데이터: Safe and Unsafe 설비 개입 클립 40개(무작위, 학습용으로만), 프레스 평소 작업 14개, 약한 라벨 사고 영상의 사고 5초 전보다 앞 구간, 검증 영상의 정상 구간
- 모델: 표준화 → PCA 32차원 → 정상 분포의 마할라노비스 거리(평소와 얼마나 다른 동작인가)
- 문턱: **정상 학습 데이터 거리의 99번째 백분위** (시험 데이터를 보지 않고 정함)
- 사고 라벨을 하나도 쓰지 않으므로 검증 영상 10개도 함께 채점한다

## B. 약한 라벨로 사고 늘리기
- 수집 영상 중 영상 검토 때 닿은 시각을 프레임 단위로 확인한 사고 18건(시험용과 같은 사고 A04·B38·B41·C03, 검증용과 같은 사고 A09·A10·B01·B02·B17은 뺌): A01(34.9초), A03(17.6), A07(14.3), A08(9.9), B03(15.5), B04(7.6), B05(71.3), B06(7.4), B08(5.0), B09(138.8), B15(15.4), B21(19.6), B22(18.4), B31(37.5), B33(27.0), B35(33.3), B37(11.6), B39(17.8)
- 약한 라벨: 닿기 2초 전부터 닿을 때까지 = 정지, 닿기 5초 전보다 앞 = 정상, 그 사이와 닿은 뒤는 쓰지 않음. 구간은 닿기 10초 전 ~ 0.5초 뒤
- 학습: 약한 라벨 사고 + 검증 사고 9건(세훈 판단표) + 프레스 평소 작업 + Safe and Unsafe 정상 40개. 동작 표현만(512) → 로지스틱 회귀(클래스 가중치 균형). 문턱 0.5
- 비교: 실험 25 MotionBERT(사고 9건만, 시험 6/10)
