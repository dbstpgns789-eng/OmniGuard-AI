# 08. 공장 사고 CCTV 데모 5건: 사고 직전에 정지하는가

## 질문

실제 공장 사고 영상에 파이프라인을 돌리면, 손이 회전체에 닿기 전에 정지가 뜨고, 정상 작업 중에는 뜨지 않는가.

## 조건 (실행 전에 정함)

- 영상 5건(`cases.json`): 빨간 상의 롤 권취기 2버전(편집본, 모니터 촬영본), 야간 종이 롤, 필름·봉투기, 판지 슬리터. 영상은 레포 밖 `OmniGuard-data/raw_cctv/`
- 화면 보정: 고정 카메라는 없음, 편집본은 affine, 모니터 촬영본은 homography. 기준 프레임에 그린 위험한계를 프레임마다 옮김
- 정답(`labels.json`): 1초 단위로 닿음(Y) / 안 닿음(N) / 판단 불가(U). 시스템 출력을 보기 전에 1초 간격 시트를 보고 정함. U는 채점 제외
- 비교: V1(손목이 위험한계와 겹침) vs V3(겹침 + 최근 1초 안에 회전체 쪽으로 1.2 몸통/초 이상 접근, 또는 TTC 0.5초 미만). 정지는 3프레임 연속 확인
- 포즈: rtmlib `Body` lightweight, CPU

## 결과 1: 프레임 비율 (`result.json`)

| 영상 | 방식 | 닿음 프레임에서 정지 | 안 닿음 프레임에서 정지(오정지) | 판단 불가 비율 |
|---|---|---|---|---|
| 빨간 상의 편집본 | V1 / V3 | 0.46 / 0.19 | 0.079 / 0.061 | 14% |
| 빨간 상의 모니터 | V1 / V3 | 0.07 / 0.01 | 0.114 / **0.034** | 46% |
| 야간 종이 롤 | V1 / V3 | 0.00 / 0.00 | 0.639 / **0.130** | 7% |
| 필름·봉투기 | V1 / V3 | 0.02 / 0.00 | 0.779 / **0.273** | 83% |
| 판지 슬리터 | V1 / V3 | 0.00 / 0.00 | (N 없음) | 75% |

## 결과 2: 정지를 유지(래치)한다고 가정했을 때 (`latched.json`)

실제 안전 장치는 정지 신호를 한 번 내면 사람이 해제할 때까지 멈춘 상태를 유지한다. 그래서 정지가 "켜진 횟수"를 셌다.

| 영상 | 방식 | 정지 켜짐 횟수 | 그중 안 닿음 구간(헛정지) | 접촉 직전 3초 안에 켜짐 |
|---|---|---|---|---|
| 빨간 상의 편집본 | V1 / V3 | 26 / 14 | 7 / 7 | 3 / 1 |
| 빨간 상의 모니터 | V1 / V3 | 25 / 16 | 14 / 6 | 1 / 1 |
| 야간 종이 롤 | V1 / V3 | 3 / 1 | 3 / 1 | 1 / 0 |
| 필름·봉투기 | V1 / V3 | 7 / 4 | 0 / 1 | 0 / 0 |
| 판지 슬리터 | V1 / V3 | 4 / 0 | 0 / 0 | 1 / 0 |

## 해석

1. **"사고 직전에 깔끔하게 정지하는 데모"는 지금 시스템으로 나오지 않는다.** 정지를 유지하면 다섯 영상 모두 사고 수십 초 전부터 기계가 멈춰 있었을 것이다. 그런데 그 정지의 대부분은 작업자가 설비 옆을 걷거나 서 있을 때 생긴 헛정지다(빨간 상의 편집본 V3: 14번 중 7번이 안 닿음 구간). 정지를 유지하지 않으면, 정지가 깜빡이다가 정작 닿는 순간에는 꺼져 있다.
2. **V3는 헛정지를 줄인다.** 오정지 비율이 다섯 영상 모두에서 줄었다(0.639 → 0.130, 0.779 → 0.273 등). 그래도 1분에 몇 번씩 헛정지가 나는 수준이라 현장에 쓸 수 없다.
3. **닿은 뒤의 정지 비율이 낮은 것은 포즈 실패 때문이다.** 몸이 설비 안으로 들어가거나 모자이크가 덮이면 관절을 잡지 못한다(실험 03과 같음).
4. **판단 불가가 많다(7~83%).** 사람 눈으로도 평면 화면에서 "닿았는가"를 구별하지 못하는 프레임이 이만큼 있다. 2D 카메라 한 대의 근본 한계를 보여 주는 숫자다.
5. 사후에 위험한계를 좁히는 등 영상에 맞춰 고치면 결과는 좋아지겠지만, 그것은 정답을 본 뒤 맞추는 것이라 하지 않았다.

## 결론

현장 영상은 "이 시스템이 실제 공장에서 바로 통한다"가 아니라 **"실제 공장 CCTV에서는 이런 이유로 아직 통하지 않는다(헛정지, 깊이, 가림)"**를 보여 주는 근거다. 성능 수치는 카메라 위치와 정답을 통제한 러닝머신 영상으로 낸다.
